# Документация: Оптимизация изображений

## 📋 Обзор

В проекте реализована комплексная система оптимизации изображений для:
- Уменьшения размера файлов (экономия 60-80% места)
- Ускорения загрузки страниц
- Улучшения пользовательского опыта
- Автоматической конвертации в WebP формат

---

## ✅ Проверка API - Все используют оптимизацию

### 1. Загрузка аватаров пользователей

## 🛠️ Инструменты для оптимизации существующих изображений

### 1. Оптимизация аватаров пользователей

**Страница:** `/admin/optimize-avatars`

**API:** `POST /api/admin/optimize-avatars`

**Функции:**
- Пакетная обработка аватаров (по 10 за раз)
- Автоматическое скачивание, оптимизация и загрузка обратно
- Пропуск уже оптимизированных изображений
- Статистика по экономии места

**Использование:**
1. Откройте `/admin/optimize-avatars` в админ-панели
2. Посмотрите статистику (сколько аватаров нужно оптимизировать)
3. Нажмите "Начать оптимизацию"
4. Дождитесь завершения процесса

**Файлы:**
- `app/admin/optimize-avatars/page.tsx` - интерфейс
- `app/api/admin/optimize-avatars/route.ts` - API endpoint

---

### 2. Универсальная оптимизация всех изображений

**Страница:** `/admin/optimize-images`

**API:** `POST /api/admin/optimize-images`

**Поддерживаемые типы:**
- **Посты** - изображения в постах пользователей (`PostAttachment`)
- **Чат** - изображения в сообщениях чата (`ChatMessageAttachment`)
- **Новости** - обложки новостей (`NewsPost.coverImage`)
- **Аватары** - аватары пользователей (`User.avatarUrl`)
- **Все** - все типы изображений одновременно

**Функции:**
- Выбор типа изображений для оптимизации
- Пакетная обработка (по 10 за раз)
- Детальная статистика по каждому типу
- Прогресс-бар обработки
- Подсчет общей экономии места

**Использование:**
1. Откройте `/admin/optimize-images` в админ-панели
2. Посмотрите статистику по каждому типу изображений
3. Выберите тип для оптимизации (или "Все изображения")
4. Нажмите "Начать оптимизацию"
5. Следите за прогрессом и результатами

**Файлы:**
- `app/admin/optimize-images/page.tsx` - интерфейс
- `app/api/admin/optimize-images/route.ts` - API endpoint

## 🔧 Технические детали

### Библиотека оптимизации

**Файл:** `lib/image-optimizer.ts`

**Использует:**
- `sharp` - для обработки изображений
- Автоматический поворот на основе EXIF
- Удаление метаданных
- Конвертация в WebP

**Пресеты:**
```typescript
avatar: {
  maxWidth: 400,
  maxHeight: 400,
  quality: 85,
  format: "webp"
}

post: {
  maxWidth: 1200,
  maxHeight: 1200,
  quality: 85,
  format: "webp"
}

cover: {
  maxWidth: 1920,
  maxHeight: 1080,
  quality: 85,
  format: "webp"
}
```

### Хранилище

Все оптимизированные изображения загружаются на VDS через:
- `lib/vds-storage.ts` - утилита для работы с VDS хранилищем
- Автоматическое создание директорий
- Поддержка SSH/SCP загрузки

## 📈 Ожидаемые результаты

### Экономия места
- **Обычно:** 60-80% экономии
- **Пример:** 5MB → 1MB (80% экономии)
- **Аватары:** 500KB → 100KB (80% экономии)

### Ускорение загрузки
- **Страницы с изображениями:** в 5-10 раз быстрее
- **Мобильные устройства:** значительное улучшение
- **CDN:** меньше трафика

### Качество
- **Визуально:** практически без потери качества
- **WebP:** современный формат с лучшим сжатием
- **Автоматический поворот:** на основе EXIF данных

## 🚀 Автоматическая оптимизация

Все новые загрузки изображений **автоматически оптимизируются** при загрузке:

1. Пользователь загружает изображение
2. Система определяет тип (аватар, пост, новость, чат)
3. Применяется соответствующий пресет оптимизации
4. Изображение конвертируется в WebP
5. Загружается на VDS
6. Сохраняется в БД

**Никаких дополнительных действий не требуется!**

---

## 🔄 Оптимизация существующих изображений

Для оптимизации уже загруженных изображений:

1. **Аватары:** Используйте `/admin/optimize-avatars`
2. **Все изображения:** Используйте `/admin/optimize-images`

**Процесс:**
1. Система находит все неоптимизированные изображения
2. Скачивает каждое изображение
3. Оптимизирует с помощью `sharp`
4. Загружает обратно на VDS
5. Обновляет пути в базе данных
6. Показывает статистику экономии

Все операции логируются в консоль:

```
[posts/upload-image] Image optimized: 2048.5KB -> 245.3KB (88% saved)
[optimize-images] Processing post attachment abc123
[optimize-images] ✅ Successfully optimized avatar for user xyz789
```

---

## ⚠️ Важные замечания

1. **Data URLs:** Пропускаются при оптимизации (они уже в памяти)
2. **GIF:** Не оптимизируются (сохраняют анимацию)
3. **Уже оптимизированные:** Пропускаются (содержат `.webp` в пути)
4. **Ошибки:** Логируются, но не останавливают процесс

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли сервера
2. Убедитесь, что VDS storage настроен
3. Проверьте права доступа (только SUPER_ADMIN)
4. Убедитесь, что `sharp` установлен: `pnpm install sharp`
