## ✅ Преимущества системы

### 1. **Точность данных**
- ✅ Используются официальные названия из ЕГРЮЛ
- ✅ Проверка действующих организаций (статус "ACTIVE")
- ✅ ИНН, ОГРН, адрес организации

### 2. **Удобство для пользователя**
- 🎯 Пользователь может написать сокращенно: "БСМП"
- 🎯 Система находит: "ГАУЗ «Больница скорой медицинской помощи города Набережные Челны»"
- 🎯 Пользователь подтверждает правильность

### 3. **Умная обработка**
- 🧠 Поиск работает даже при опечатках
- 🧠 Учитывается регион пользователя для точности
- 🧠 Распознаются НКО и профсоюзы

## 🔧 Техническая реализация

### Файл: `lib/organization-search.ts`

```typescript
export async function findOrganization(
  organizationName: string,
  region?: string
): Promise<{ id?: string; name: string; foundInDatabase: boolean } | null> {
  
  // Шаг 1: Поиск в локальной БД МойСоюз
  const dbOrg = await searchOrganizationInDatabase(normalizedName, region);
  if (dbOrg) {
    return {
      id: dbOrg.id,
      name: dbOrg.name,
      foundInDatabase: true,  // ✅ Найдено в нашей БД
    };
  }

  // Шаг 2: Поиск через DaData API → ЕГРЮЛ/Минюст РФ
  const minjustOrg = await searchOrganizationInMinjust(normalizedName, region);
  if (minjustOrg) {
    return {
      name: minjustOrg.name,
      foundInDatabase: false,  // ℹ️ Найдено в реестре Минюста
    };
  }

  return null;  // ❌ Не найдено нигде
}
```

### API запрос к DaData


## ⚙️ Настройка

### 1. Получите API ключ DaData

1. Зарегистрируйтесь на [dadata.ru](https://dadata.ru/)
2. Бесплатный тариф: **10,000 запросов в день**
3. Скопируйте API токен из личного кабинета

### 2. Добавьте в `.env.local`

```bash
DADATA_API_KEY="ваш_токен_здесь"
```

### 3. Перезапустите сервер

```bash
npm run dev
```

## 🔍 Что проверяется

### Источники данных

1. **Локальная база МойСоюз**
   - Профсоюзные организации
   - ППО (первичные профсоюзные организации)
   - Региональные отделения

2. **ЕГРЮЛ через DaData**
   - Все юридические лица РФ
   - Государственные учреждения (ГАУЗ, МБУЗ и т.д.)
   - Некоммерческие организации (НКО)
   - Профсоюзы

### Фильтры

- ✅ Только **активные** организации (`status: ACTIVE`)
- ✅ Приоритет **НКО и профсоюзам**
- ✅ Учет **региона** пользователя

### Логи для отладки

```javascript
console.log("[organization-search] Organization found in DaData/Minjust: ...");
console.log("[organization-search] Organization not found in DaData: ...");
console.log("[organization-search] DaData API error: 403");
```

### Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `DaData API key not configured` | Не установлен ключ | Добавить `DADATA_API_KEY` в `.env.local` |
| `DaData API error: 403` | Неверный ключ | Проверить правильность токена |
| `DaData API error: 429` | Превышен лимит | Подождать или увеличить тариф |
| `Organization not found` | Организации нет в ЕГРЮЛ | Попросить пользователя уточнить |
