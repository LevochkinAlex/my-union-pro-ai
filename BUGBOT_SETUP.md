# 🐛 Настройка Bugbot от Cursor

## Что такое Bugbot?

Bugbot - это автоматический анализатор кода от Cursor, который проверяет ваши pull request'ы в GitHub и оставляет комментарии с найденными проблемами и предложениями по исправлению.

## 📋 Шаги настройки

### 1. Подключение GitHub к Cursor

1. Перейдите в [панель управления Cursor](https://cursor.com/dashboard)
2. Войдите в свой аккаунт Cursor
3. Перейдите на вкладку **"Integrations"**
4. Найдите **GitHub** и нажмите **"Connect"**
5. Следуйте инструкциям для установки приложения Cursor в вашей организации GitHub
6. Выберите репозитории, к которым нужно предоставить доступ

### 2. Активация Bugbot для репозитория

1. После подключения GitHub вернитесь в панель управления Cursor
2. Перейдите на вкладку **"Bugbot"**
3. Выберите репозитории, для которых вы хотите активировать Bugbot
4. Включите Bugbot для выбранных репозиториев (включая `my-union-pro-ai`)

### 3. Использование Bugbot

#### Автоматический режим:
- Bugbot автоматически анализирует все новые pull request'ы
- Оставляет комментарии с найденными проблемами
- Предлагает исправления

#### Ручной запуск:
В любом pull request'е оставьте комментарий:
```
cursor review
```
или
```
bugbot run
```

Bugbot проанализирует изменения и оставит комментарии.

## ⚠️ Требования

- Права администратора в организации GitHub
- Активная подписка Cursor с доступом к Bugbot
- Репозиторий должен быть подключен к Cursor через GitHub интеграцию

## ✅ Проверка работы

После настройки:
1. Создайте тестовый pull request
2. Bugbot должен автоматически проанализировать изменения
3. Проверьте комментарии в PR

---

**Примечание**: Bugbot работает только с GitHub репозиториями и не требует изменений в коде проекта.
