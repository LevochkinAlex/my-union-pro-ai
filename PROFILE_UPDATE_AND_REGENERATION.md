# 🔄 Система проверки профиля и перегенерации документов

> **Реализовано:** 24 ноября 2025  
> **Задача:** После заполнения заявления пользователь может проверить профиль и перегенерировать документы при изменении данных

---

## 📋 Что реализовано

### 1. Кнопка "Проверить профиль" в чате ✅

После генерации документов пользователь видит **две кнопки**:
- 📥 **Скачать документы** - открывает раздел документов
- 👤 **Проверить профиль** - открывает страницу профиля для проверки/редактирования

**Файл:** `components/chat/Chat.tsx` (строки 887-920)

```tsx
<div className="flex flex-col sm:flex-row items-center justify-center gap-3">
  <button onClick={() => window.open("/dashboard/documents", "_blank")}>
    Скачать документы
  </button>
  <button onClick={() => window.open("/dashboard/profile", "_blank")}>
    Проверить профиль
  </button>
</div>
```

---

### 2. Механизм отслеживания изменений профиля ✅

**Добавлены поля в БД:**
- `profileChangedAfterDocuments` (Boolean) - флаг изменения данных
- `profileLastModified` (DateTime) - дата последнего изменения

**Миграция:** `prisma/migrations/20251124214657_add_profile_change_tracking/migration.sql`

**Отслеживаемые поля:**
- ФИО (firstName, lastName, middleName)
- Дата рождения (dateOfBirth)
- Телефон (phone)
- Адрес (address)
- Должность (jobTitle)
- Профессия (profession)
- Образование (education)

**Файл:** `app/api/profile/route.ts` (строки 123-174)

**Логика:**
```typescript
// При обновлении профиля проверяем:
1. Изменились ли ключевые поля
2. Есть ли уже сгенерированные документы
3. Если да → устанавливаем profileChangedAfterDocuments = true
```

---

### 3. Баннер в разделе "Документы" ✅

Когда `profileChangedAfterDocuments = true`, показывается **оранжевый баннер**:

**Содержимое:**
- ⚠️ Предупреждение об изменении данных
- 📝 Объяснение почему нужна перегенерация
- 🔄 Кнопка "Перегенерировать документы"
- 👤 Кнопка "Проверить профиль"

**Файл:** `app/dashboard/documents/page.tsx` (строки 200-245)

**Внешний вид:**
- Цвет: Оранжевый (предупреждение)
- Иконка: Треугольник с восклицательным знаком
- Адаптивный дизайн (mobile + desktop)

---

### 4. API перегенерации документов ✅

**Endpoint:** `POST /api/documents/regenerate`

**Что делает:**
1. Проверяет авторизацию
2. Проверяет полноту профиля
3. Генерирует новые PDF с актуальными данными
4. Обновляет записи в БД (или создает новые)
5. Сбрасывает флаг `profileChangedAfterDocuments = false`

**Файл:** `app/api/documents/regenerate/route.ts`

**Безопасность:**
- ✅ Требует авторизации
- ✅ Проверяет полноту профиля
- ✅ Запрашивает подтверждение перед перегенерацией
- ✅ Логирование всех операций

## 🔧 Технические детали

### База данных

**Модель User:**
```prisma
model User {
  // ... другие поля
  
  profileChangedAfterDocuments Boolean @default(false)
  profileLastModified          DateTime?
  
  // ... другие поля
}
```

### API Endpoints

**GET /api/profile**
- Возвращает `profileChangedAfterDocuments` и `profileLastModified`

**PUT /api/profile**
- Отслеживает изменения ключевых полей
- Устанавливает флаг если есть документы

**POST /api/documents/regenerate**
- Перегенерирует документы
- Сбрасывает флаг после успеха

### Логирование

Все операции логируются:
```
[regenerate-documents] Regenerating documents for user: user@example.com
[regenerate-documents] PDF files generated: { ... }
[regenerate-documents] ✅ Membership application updated
[regenerate-documents] ✅ Contributions application updated
[regenerate-documents] ✅ Documents regenerated successfully
```
