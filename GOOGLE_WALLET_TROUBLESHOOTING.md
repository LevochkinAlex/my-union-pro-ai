# 🔧 Отладка Google Wallet на Android

## Что проверить:

### 1. Проверьте логи сервера

Когда нажимаете "Скачать" на Android, смотрите логи в терминале где запущен `pnpm dev`:

Ищите сообщения:
- `[Google Pay API] Creating discount pass:`
- `[createDiscountPass] Starting with:`
- `[createLoyaltyClass]` или `[createLoyaltyObject]`
- `[generateSaveJWT]`
- Ошибки с `[Error]` или `[createLoyaltyObject] Error:`

### 2. Проверьте консоль браузера на Android

Откройте Chrome на компьютере и подключите Android устройство:
1. В Chrome: `chrome://inspect`
2. На Android: Настройки → Для разработчиков → Отладка по USB
3. Подключите устройство и выберите его в Chrome
4. Откройте приложение на Android
5. Нажмите "Скачать"
6. Смотрите логи в консоли

Ищите:
- `[Google Wallet] Starting download for Android:`
- `[Google Wallet] API response status:`
- `[Google Wallet] API response data:`
- Ошибки

### 3. Проверьте сетевые запросы

В Chrome DevTools на вкладке Network проверьте запрос к `/api/wallet/google-pass`:
- Какой статус ответа (200, 401, 403, 500)?
- Что в ответе (JSON)?
- Есть ли ошибки?

### 4. Типичные ошибки и решения:

#### 401 Unauthorized
**Причина:** Проблема с Service Account ключом
**Решение:** 
- Проверьте `FIREBASE_PRIVATE_KEY` в `.env.local`
- Убедитесь, что ключ правильно скопирован (с `\n`)

#### 403 Forbidden
**Причина:** Недостаточно прав Service Account
**Решение:**
- Убедитесь, что Google Wallet API включен
- Проверьте права Service Account в IAM

#### 404 Not Found
**Причина:** Неправильный Issuer ID или API не включен
**Решение:**
- Проверьте `GOOGLE_PAY_ISSUER_ID=3388000000023063666` в `.env.local`
- Убедитесь, что Google Wallet API включен

#### 500 Internal Server Error
**Причина:** Ошибка в коде
**Решение:**
- Проверьте логи сервера
- Посмотрите на детали ошибки

#### Ответ успешный, но ничего не происходит
**Причина:** Проблема с JWT или URL
**Решение:**
- Проверьте логи `[generateSaveJWT]`
- Убедитесь, что `saveUrl` или `jwt` присутствуют в ответе
- Проверьте, что URL правильный: `https://pay.google.com/gp/v/save/...`

### 5. Быстрая проверка:

1. Откройте терминал с логами сервера
2. На Android нажмите "Скачать"
3. Смотрите что выводится в логи
4. Скопируйте ошибку (если есть) и сообщите мне

## Следующие шаги:

После проверки логов мы сможем понять, в чем проблема:
- Если ошибка в API → исправим код
- Если проблема с правами → добавим роль
- Если проблема с JWT → исправим генерацию
- Если всё работает на сервере → проверим клиентскую часть
