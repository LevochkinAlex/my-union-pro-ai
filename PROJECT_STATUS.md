## 🔄 Инструкция по переносу работы на другой Mac

Чтобы продолжить разработку на другом компьютере и не потерять контекст:

1. **Код проекта**:
   - Сделай `git push` на текущей машине (все изменения закоммичены).
   - На новом Mac: `git clone <repo_url>`

2. **Переменные окружения (.env)**:
   - Скопируй файл `.env` или `.env.local` с текущего Mac на новый. (Ключи API, доступы к БД не хранятся в git).

3. **Контекст Cursor (AI Память)**:
   - В текущем чате Cursor нажми кнопку **"Скопировать для Cursor"** (над полем ввода сообщения).
   - Это скопирует весь диалог в буфер обмена в формате Markdown.
   - На новом Mac открой Cursor -> New Chat -> Вставь скопированный текст.
   - AI прочитает историю и поймет, на чем мы остановились.

4. **Запуск на новом месте**:
   ```bash
   pnpm install
   pnpm prisma generate
   pnpm dev
   ```
