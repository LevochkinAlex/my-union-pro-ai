# Исправление проблем поиска и загрузки скидок

## Проблемы, которые были найдены:

### 1. ✅ API поиска работает корректно
- BestBenefits API находит "пятерочка" (2 скидки: ID 4313 "Пятёрочка доставка", ID 4314)
- Endpoint `/api/search` возвращает правильные результаты
- Нормализация данных работает правильно (`name` → `title`)

### 2. ⚠️ Несоответствие limit
**Проблема:** Клиент запрашивает 20 скидок, а сервер по умолчанию возвращает 15
**Решение:** Увеличен limit по умолчанию с 15 до 20 в `lib/best-benefits.ts`

```typescript
limit: params.limit ?? 20, // Было 15
```

### 3. ⚠️ Всего 2972 скидки доступно
- API BestBenefits содержит 2972 скидки (30 страниц по 100)
- Загружается только первая страница при начальной загрузке
- Остальные страницы загружаются через бесконечный скролл (IntersectionObserver)

### 4. ✅ Бесконечный скролл работает правильно
- Реализован через IntersectionObserver
- Загружает следующую страницу при достижении конца списка
- Debounce 150ms для предотвращения множественных запросов

## Возможные причины, почему "пятерочка" не находится:

### 1. ❌ Скидка недоступна для вашего аккаунта
- У разных аккаунтов BestBenefits разные доступные скидки
- Проверьте на сайте BestBenefits, доступна ли "Пятёрочка" для вашего аккаунта

### 2. ❌ Фильтр по городу слишком строгий
- Пятёрочка может быть доступна только в определенных городах
- Или наоборот - глобальная скидка (cities: [])
- Проверьте:
  ```javascript
  // В cities: [] означает "Онлайн" (доступно везде)
  cities: cityList.length > 0 ? cityList : [{ id: 0, name: "Онлайн" }]
  ```

### 3. ❌ Кэширование
- Результаты могут кэшироваться на 30 секунд:
  ```typescript
  "Cache-Control": "private, max-age=30"
  ```
- Попробуйте hard refresh (Cmd+Shift+R / Ctrl+Shift+F5)

### 4. ✅ Скидка на другой странице
- При общем просмотре скидка может быть не на первой странице
- Прокрутите вниз или используйте поиск
