# 🎫 Как будут выглядеть скидки в Wallet

## 📱 Android (Google Wallet)

### Внешний вид:
- **Тип:** Loyalty Card (Карта лояльности)
- **Название программы:** "Скидки и льготы"
- **Название эмитента:** "MyUnion Pro"
- **Заголовок:** Название скидки (например: "Скидка 20% в магазине X")
- **QR-код:** Если есть промокод, будет отображаться QR-код
- **Имя пользователя:** Имя пользователя, для которого создана скидка
- **Срок действия:** Дата окончания действия скидки (если указана)
- **Изображение:** Логотип или изображение скидки (если есть)

### Где находится:
- В приложении Google Wallet (Google Pay)
- Доступно через Google Pay на главном экране
- Можно добавить на главный экран Android как ярлык

### Как использовать:
1. Открыть Google Wallet
2. Найти карточку скидки
3. Нажать на неё для просмотра
4. Показать QR-код кассиру (если есть)
5. Или назвать промокод (если есть)

## 🍎 iOS (Apple Wallet)

### Внешний вид (после настройки API):
- **Тип:** Store Card (Карта магазина)
- **Название:** Название скидки
- **Промокод:** Отображается крупным шрифтом
- **QR-код:** Если есть промокод, будет QR-код
- **Срок действия:** Дата окончания действия
- **Изображение:** Логотип или изображение скидки

### Где находится:
- В приложении Apple Wallet
- Доступно через Apple Wallet на главном экране
- Можно добавить на главный экран iOS как виджет

### Как использовать:
1. Дважды нажать кнопку питания (или кнопку Home на старых iPhone)
2. Выбрать карточку из Apple Wallet
3. Показать QR-код или промокод кассиру

### ⚠️ Текущий статус:
Сейчас Apple Wallet API не настроен, поэтому на iOS будет скачиваться PNG изображение, которое можно сохранить в галерею.

## 💻 Desktop (ПК/Mac)

### Внешний вид:
- **Формат:** PDF файл
- **Содержание:** Та же карточка, что и в модальном окне
- **Размер:** A4 или под размер изображения

### Где находится:
- Открывается в новой вкладке браузера
- Можно скачать через браузер
- Можно сохранить на компьютер

### Как использовать:
1. Открыть PDF
2. Распечатать (если нужно)
3. Или показать с экрана (QR-код или промокод)

## 📋 Структура данных в пропуске

### Для Google Wallet (Android):
```javascript
{
  issuerName: "MyUnion Pro",
  programName: "Скидки и льготы",
  discountTitle: "Название скидки",
  promoCode: "ПРОМОКОД123", // если есть
  userName: "Имя Фамилия",
  validUntil: "2024-12-31", // если указан срок
  imageUrl: "URL изображения", // если есть
  QR-код: "ПРОМОКОД123" // генерируется автоматически
}
```

### Для Apple Wallet (iOS):
```javascript
{
  description: "Название скидки",
  storeCard: {
    primaryFields: [{ key: "title", value: "Название скидки" }],
    secondaryFields: [{ key: "code", value: "ПРОМОКОД123" }],
    barcode: { format: "PKBarcodeFormatQR", message: "ПРОМОКОД123" }
  }
}
```

## ✅ Преимущества использования Wallet

1. **Удобство:** Все скидки в одном месте
2. **Быстрый доступ:** Не нужно искать в приложении
3. **Оффлайн доступ:** Работает без интернета
4. **Автоматические обновления:** Можно обновлять информацию о скидке
5. **Безопасность:** Защищенная передача данных
