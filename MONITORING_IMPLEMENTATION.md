## 🚀 Что делать сейчас

### Шаг 1: Использовать свой мониторинг (уже готово!)
```bash
# Проверить системные метрики
curl https://myunion.pro/api/admin/system-metrics \
  -H "Cookie: next-auth.session-token=YOUR_TOKEN"

# Проверить производительность
curl https://myunion.pro/api/admin/performance \
  -H "Cookie: next-auth.session-token=YOUR_TOKEN"
```

### Шаг 2: Добавить Sentry (опционально, 30 минут)

1. Регистрация: https://sentry.io/signup/
2. Создать проект (Next.js)
3. Установить SDK:
```bash
pnpm add @sentry/nextjs
```

4. Инициализация:
```typescript
// sentry.client.config.ts
import * as Sentry from "@sentry/nextjs";

Sentry.init({
  dsn: process.env.NEXT_PUBLIC_SENTRY_DSN,
  tracesSampleRate: 0.1, // 10% запросов
  environment: process.env.NODE_ENV,
});
```

5. Интеграция с Logger:
```typescript
// lib/logger.ts
import * as Sentry from "@sentry/nextjs";

// В методе error():
if (entry.level === "ERROR" || entry.level === "CRITICAL") {
  Sentry.captureException(error, {
    level: entry.level === "CRITICAL" ? "fatal" : "error",
    tags: { source: entry.source },
    extra: entry.details,
  });
}
```

### Шаг 3: Настроить Grafana (опционально, 2-3 часа)

1. Установка на сервере:
```bash
# Prometheus
wget https://github.com/prometheus/prometheus/releases/download/v2.45.0/prometheus-2.45.0.linux-amd64.tar.gz

# Grafana
wget https://dl.grafana.com/oss/release/grafana-10.0.0.linux-amd64.tar.gz
```

2. Настройка экспортеров:
- Node.js exporter для системных метрик
- PostgreSQL exporter для БД
- Redis exporter для Redis

3. Создание дашбордов в Grafana
