# Система управления телефонами

## Обзор изменений

### 1. Нормализация телефонов
Все телефоны теперь хранятся в едином формате: `+7XXXXXXXXXX`

**Утилиты** (`lib/utils/phone.ts`):
- `normalizePhone(phone)` - нормализует номер в формат +7...
- `getPhoneDigits(phone)` - возвращает только цифры
- `formatPhoneDisplay(phone)` - форматирует для отображения: +7 (XXX) XXX-XX-XX
- `isSamePhone(phone1, phone2)` - сравнивает номера с учётом разных форматов
- `maskPhone(phone)` - маскирует номер: +7 (***) ***-**-86

### 2. Новые поля в User
```prisma
model User {
  phone       String?  @unique // Текущий телефон (может меняться)
  authPhone   String?  @unique // Телефон первой авторизации (НЕ меняется)
  phoneHistory PhoneHistory[]  // История изменений
}
```

### 3. Таблица PhoneHistory
```prisma
model PhoneHistory {
  id              String @id
  userId          String
  phone           String    // Нормализованный номер
  phoneNormalized String    // Только цифры
  changeType      String    // AUTH, PROFILE_UPDATE, MERGE
  previousPhone   String?   // Предыдущий номер
  source          String?   // telegram, sms, profile, admin
  ipAddress       String?
  notes           String?
  createdAt       DateTime
}
```

### 4. Автосохранение
- Поля сохраняются автоматически при потере фокуса (onBlur)
- Индикатор статуса сохранения в заголовке модалки
- Поля с автосохранением: firstName, lastName, middleName, phone, address

### 5. Обработка конфликтов
При попытке указать телефон, занятый другим пользователем:
- Показывается предупреждение с именем существующего пользователя
- Предлагается вернуть исходный номер
- API возвращает статус 409 (Conflict) с информацией о возможности объединения

### 6. Улучшения UX
- Точные сообщения об ошибках (вместо общего "Ошибка сохранения")
- Индикация изменённого телефона (⚠️ Изменён)
- Отображение исходного номера при изменении

## Логика при авторизации

При первой авторизации через Telegram/SMS:
1. Телефон записывается в `phone` и `authPhone`
2. Создаётся запись в PhoneHistory с changeType="AUTH"

При изменении телефона в профиле:
1. Проверяется уникальность нового номера
2. Если номер занят - возвращается ошибка 409 с предложением объединить
3. Если свободен - обновляется `phone`, создаётся запись в PhoneHistory

## Безопасность

- `authPhone` никогда не меняется (используется для восстановления доступа)
- История изменений телефонов хранится для аудита
- При конфликте можно предложить объединение аккаунтов (через поддержку)
