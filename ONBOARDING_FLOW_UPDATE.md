### 2. ✅ Принудительное заполнение анкеты

**Создан endpoint:** `app/api/chat/check-application/route.ts`

**Изменено в:** `components/chat/Chat.tsx`

**Функционал:**
- При загрузке STATEMENT сессии автоматически проверяется заполненность заявления
- Если профиль не заполнен ИЛИ документы не сгенерированы — модальное окно открывается принудительно
- Чат блокируется до заполнения анкеты:
  - Поле ввода отключено
  - Кнопка отправки неактивна
  - Плейсхолдер: "Сначала заполните анкету для подачи заявления..."

**Логика проверки:**
```typescript
// Проверка полноты профиля
const profileComplete = isProfileComplete(user);

// Проверка наличия сгенерированных документов
const hasMembershipApp = documents.some(d => d.type === "MEMBERSHIP_APPLICATION");
const hasContributionApp = documents.some(d => d.type === "CONTRIBUTION_APPLICATION");

// Заявление заполнено, если профиль заполнен И документы сгенерированы
const applicationFilled = profileComplete && hasMembershipApp && hasContributionApp;
```

**Поведение модального окна:**
- Не закрывается при клике вне окна (если заявление не заполнено)
- Проверка при закрытии: если заявление не заполнено — окно не закрывается
- Перезагружает состояние чата после успешного заполнения

### 7. ✅ Персонализация консультаций бота

**Изменено в:** `app/api/chat/route.ts` (функция `buildSystemPrompt`)

**Добавлен блок:**

```typescript
// Добавляем информацию о пользователе для персонализации
if (user && sessionType) {
  const userName = [user.lastName, user.firstName, user.middleName].filter(Boolean).join(' ');
  const userInfo = [];
  
  if (userName) userInfo.push(`Имя: ${userName}`);
  if (user.organizationName) userInfo.push(`Организация: ${user.organizationName}`);
  if (user.jobTitle) userInfo.push(`Должность: ${user.jobTitle}`);
  if (user.profession) userInfo.push(`Профессия: ${user.profession}`);
  if (user.region) userInfo.push(`Регион: ${user.region}`);
  
  if (userInfo.length > 0) {
    prompt += `\n\n## ИНФОРМАЦИЯ О ПОЛЬЗОВАТЕЛЕ:

Ты общаешься с пользователем, информация о котором:
${userInfo.join('\n')}

  }
```

## 🎯 Итоговый флоу онбординга

### Новый пользователь:

1. **Заход в приложение** → Переход на "Мой бот"
2. **Приветствие AI-бота** → Рассказ о возможностях + кнопка "Заполнить анкету"
3. **Принудительное открытие анкеты** → Чат заблокирован до заполнения
4. **Шаг 1: Основные данные** (33% прогресс)
   - ФИО, дата рождения, телефон
   - Адрес (с подсказками DaData)
   - Организация
   - Должность (автокомплит из справочника)
   - Профессия (автокомплит из справочника)
   - Образование
5. **Шаг 2: Загрузка документов** (66% прогресс)
   - Скачивание пустых бланков
   - Заполнение и подписание
   - Загрузка обратно
6. **Шаг 3: Дополнительная информация** (100% прогресс)
   - Занятость, семейное положение, дети, хобби и т.д.
   - Кнопка "Заполнить позже" для пропуска
7. **Завершение** → Чат разблокирован, бот готов консультировать

### Вернувшийся пользователь:

1. **Если заявление заполнено:** Чат работает нормально, бот знает контекст пользователя
2. **Если заявление не заполнено:** Принудительная модалка с анкетой

## 🚀 Преимущества нового подхода

1. **Качество данных:** Все данные заполняются через валидированную форму
2. **UX:** Понятный пошаговый процесс с визуальным прогрессом

4. **Гибкость:** Можно пропустить необязательные поля
