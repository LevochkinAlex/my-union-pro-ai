# Госуслуги (ЕСИА): что делать после загрузки сертификата

Вы добавили систему «Мой Союз» (MYUNION) на [partners.gosuslugi.ru](https://partners.gosuslugi.ru/) и загрузили сертификат. Ниже — что делать дальше на портале и в коде.

## Официальные документы

- **Регламент информационного взаимодействия участников с оператором ЕСИА** (Минцифры России, актуальная редакция):  
  [PDF на adm.digital.gov.ru](https://adm.digital.gov.ru/app/uploads/2025/11/31c70f_reglament_informaczionnogo_vzaimodejstviya_uchastnikov_s_operatorom-2.52.pdf)  
  Описывает порядок взаимодействия заявителей с Минцифры и оператором эксплуатации инфраструктуры электронного правительства при организации взаимодействия ИС с ЕСИА. При реализации входа через Госуслуги и при подаче заявок ориентируйтесь на этот регламент.

---

## 1. На портале partners.gosuslugi.ru — куда нажимать

### Вариант А: Раздел «Мои системы»

1. Зайдите на [partners.gosuslugi.ru](https://partners.gosuslugi.ru/) и откройте **Главная → Мои системы**.
2. В списке найдите систему **«Мой Союз»** (MYUNION) и **нажмите на неё** (откроется карточка системы).
3. Под блоком с названием и мнемоникой есть подраздел **«Ваши сервисы»**. Если там пусто — ищите рядом кнопку или ссылку:
   - **«Добавить сервис»** / **«Подключить сервис»** / **«Добавить решение»**  
   Нажмите её и выберите тип сервиса, связанный с **«Вход на сайт»** или **ЕСИА**.
4. В форме добавления сервиса заполните:
   - название сервиса (например, «Вход на сайт МойСоюз»);
   - **URL возврата (redirect_uri)**: `https://myunion.pro/api/auth/gosuslugi/callback`;
   - при необходимости — описание. Сохраните.
5. После сохранения в карточке системы или сервиса должны появиться **идентификатор (client_id)** и, при необходимости, **секрет (client_secret)**. Скопируйте их в надёжное место (например, в .env).

### Вариант Б: Каталог решений ЕСИА

1. В меню портала откройте **Каталог решений** (или **Каталог**) и перейдите в раздел **ЕСИА** (прямая ссылка: [partners.gosuslugi.ru/catalog/esia](https://partners.gosuslugi.ru/catalog/esia)).
2. Найдите решение **«Вход на сайт через Госуслуги»** (или аналогичное) и нажмите **«Подключить»** / **«Добавить»** / **«Подключить систему»**.
3. В мастере выберите вашу систему **«Мой Союз»** (MYUNION) из списка уже добавленных систем.
4. Укажите **URL возврата (redirect_uri)**: `https://myunion.pro/api/auth/gosuslugi/callback`.
5. Пройдите оставшиеся шаги мастера (проверка данных, отправка на модерацию — если есть). После согласования сохраните выданные **client_id** и **client_secret**.

Если на странице нет кнопки «Добавить сервис» в «Ваших сервисах», используйте **Вариант Б** (Каталог → ЕСИА → подключить решение и привязать систему Мой Союз).

### Что заполнять в любом случае

- **Шаг 2:** Добавление **сервиса** (ваш сайт как «сервис» системы) — название, тип «Вход на сайт» и т.п.
- **Шаг 3:** Указание **URL возврата (redirect_uri)** — адрес на вашем сайте, куда Госуслуги вернут пользователя после входа. Для МойСоюз это будет что-то вроде:  
  `https://myunion.pro/api/auth/gosuslugi/callback`  
  (точный путь задаётся при реализации входа в коде; он должен **совпадать** с тем, что указан на портале.)
- **Шаг 4:** Проверка данных и отправка на модерацию/подключение (если есть такая кнопка).
- **Шаг 5:** После согласования — в карточке системы или сервиса появятся **идентификаторы для интеграции**:
  - **client_id** (идентификатор ИС/сервиса),
  - **client_secret** (или инструкция по подписанию запросов сертификатом).

Сохраните эти данные в надёжное место (например, в `.env` не коммитить в git).

### Тестовая и промышленная среда

- Для **теста** часто нужно отдельно подать заявку на подключение к тестовой среде ЕСИА (например, на sd@sc.digital.gov.ru) и дождаться одобрения.
- Для **боевой** работы — после теста подаётся заявка на промышленную среду. Без одобрения «Вход через Госуслуги» на проде работать не будет.

Итого по порталу: **пройти все шаги мастера, указать redirect_uri, дождаться выдачи client_id (и при необходимости client_secret), сохранить учётные данные.**

## 2. В коде (myunion.pro)

После того как на портале будут выдан **client_id**, **client_secret** (или способ аутентификации запросов) и подтверждён **redirect_uri**, нужно реализовать на сайте поток «Вход через Госуслуги».

### Что потребуется

1. **Страница/кнопка входа**  
   На странице логина — кнопка «Войти через Госуслуги», ведущая на ваш backend, который редиректит пользователя в ЕСИА (OAuth 2.0 / OpenID Connect).

2. **Backend (API)**  
   - Маршрут, который формирует ссылку на авторизацию ЕСИА (с `client_id`, `redirect_uri`, `scope`, `state`, `nonce`) и делает редирект.  
   - Маршрут **callback** по адресу, совпадающему с **redirect_uri** (например, `https://myunion.pro/api/auth/gosuslugi/callback`). На нём:
     - принимается `code` (и при необходимости `state`);
     - выполняется обмен `code` на токен доступа (и при необходимости id_token);
     - запрашиваются данные пользователя из ЕСИА;
     - создаётся или находится пользователь в вашей БД и выполняется вход (сессия/JWT и т.д.).

3. **Реквизиты в .env**  
   - `ESIA_CLIENT_ID` (или `GOSUSLUGI_CLIENT_ID`)  
   - `ESIA_CLIENT_SECRET` (или способ подписи запросов, если ЕСИА использует только сертификат)  
   - URL тестовой/промышленной среды ЕСИА (например, из документации или выданный на портале).

4. **Документация ЕСИА**  
   - Точные URL для authorize и token, формат подписи запросов (если требуется), список scope — брать из актуальной документации ЕСИА/портала партнёров.

В репозитории пока **нет** готовой реализации входа через Госуслуги. После появления **client_id** и **redirect_uri** можно добавить маршруты и кнопку по аналогии с VK ID / Яндекс (OAuth callback + создание/поиск пользователя по данным из ЕСИА).

## 3. Краткий чек-лист

| Где | Действие |
|-----|----------|
| Портал | Пройти шаги 2–5 в каталоге ЕСИА (сервис, redirect_uri, модерация). |
| Портал | Указать redirect_uri, например: `https://myunion.pro/api/auth/gosuslugi/callback`. |
| Портал | Сохранить выданные **client_id** и **client_secret** (или инструкцию по аутентификации). |
| Портал | При необходимости подать заявку на тестовую/промышленную среду и дождаться одобрения. |
| Код | После появления реквизитов — реализовать OAuth/OpenID flow (редирект в ЕСИА + callback + создание сессии). |

Когда будут готовы **client_id**, **redirect_uri** и (при необходимости) **client_secret**, можно переходить к реализации входа на сайте.
