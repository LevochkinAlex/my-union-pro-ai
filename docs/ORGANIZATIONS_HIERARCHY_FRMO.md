# Иерархия организаций и связь с ФРМО

## Текущая модель

- **Организации** (супер-админка → «Организации»): иерархия профсоюзных организаций с типами ФПО → РПО → МПО → **ППО** (первичные). Членом можно быть только в **ППО**.
- **Связи «Место работы» → ППО** (супер-админка → «Связи место работы → ППО»): справочник пар «название + ИНН работодателя» → «ППО». По нему в анкете и профиле подставляется ППО после выбора места работы (поиск через DaData).

## ФРМО (Федеральный реестр медицинских организаций)

Внешний реестр организаций здравоохранения:  
https://portal.egisz.rosminzdrav.ru/services/frmo

Для выстраивания единой иерархии организаций здравоохранения и первичных ППО в них:

1. **Иерархию** создают в разделе «Организации»: корень (ФПО) → региональные (РПО) → местные (МПО) → первичные (ППО). Названия и привязки можно сверять с ФРМО вручную.
2. **Связи** «место работы (работодатель по ИНН/названию) → ППО» добавляют в разделе «Связи место работы → ППО». Так анкета и профиль по выбранному месту работы подставляют нужное ППО (одно — автоматически, несколько — выбор из списка).

## Возможное развитие

- Добавить в модель `Organization` поле `frmoCode` или `externalId` для привязки к коду ФРМО и последующей синхронизации/импорту из реестра, если появится API или выгрузка.
- Реализовать импорт/синхронизацию из ФРМО по официальному API или файлам выгрузки (когда станет доступно).
