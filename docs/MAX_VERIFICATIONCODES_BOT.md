# MAX: бот кодов подтверждения (verificationcodes_bot) и наша интеграция

## Что такое verificationcodes_bot

**https://max.ru/verificationcodes_bot** — официальный бот MAX, куда пользователям приходят одноразовые коды от банков, магазинов и сервисов. Пользователь один раз запускает бота и получает коды в одном месте.

## Как у нас сейчас устроена доставка кодов в MAX

Мы **уже отправляем** коды входа в MAX — но через **нашего бота «Мой Союз»**, а не через verificationcodes_bot:

1. Пользователь хотя бы раз заходит через MAX (мини-приложение или привязывает номер в чате с ботом «Мой Союз»).
2. В БД сохраняется `User.maxChatId` (идентификатор чата с нашим ботом).
3. При входе по номеру телефона в [send-pin](app/api/auth/sms/send-pin/route.ts) приоритет доставки: **Telegram → MAX (наш бот) → SMS**.
4. Если у пользователя есть `maxChatId`, код уходит в чат с ботом «Мой Союз» через [MAX Bot API](https://bot.max.ru/api) и наш `MAX_BOT_TOKEN`.

То есть коды от МойСоюз приходят **в чат с ботом «Мой Союз»**, а не в verificationcodes_bot.

## Можно ли подключить verificationcodes_bot

Публичного API для отправки кодов **именно в verificationcodes_bot** по номеру телефона в открытой документации MAX нет:

- Документация [dev.max.ru](https://dev.max.ru/docs-api) описывает **собственного бота** (токен, `platform-api.max.ru`, отправка в свой чат по `chat_id`).
- verificationcodes_bot — отдельный продукт MAX; как стороннему сервису «пробить» пользователя по номеру и отправить код в этого бота, в публичных гайдах не описано.

Чтобы доставлять коды МойСоюз **в verificationcodes_bot** (а не только в нашего бота), нужна **партнёрская/официальная интеграция** с MAX:

- Написать в поддержку/партнёрский отдел MAX (например, через [business.max.ru](https://business.max.ru) или раздел для разработчиков [dev.max.ru](https://dev.max.ru)).
- Уточнить: есть ли API или сценарий, по которому внешний сервис может отправлять коды подтверждения в verificationcodes_bot по номеру телефона пользователя, и какие условия подключения.

## Что можно сделать без партнёрства

- **Уже работает:** коды в MAX приходят в бота «Мой Союз» для пользователей с привязанным MAX (`maxChatId`).
- На странице входа под полем телефона можно явно написать, что код может прийти «в Telegram или в MAX (чат с ботом Мой Союз)», если привязаны — так пользователю проще понять приоритет доставки из [send-pin](app/api/auth/sms/send-pin/route.ts).

Итого: «подключить» verificationcodes_bot в смысле «отправлять туда наши коды по API» можно только через договорённость/API с MAX; технически мы уже подключены к MAX через своего бота и отправляем коды в чат с «Мой Союз».
