# ✅ Синхронизация пользователей с BestBenefits - Завершено

## 📋 Выполненные задачи

### 1. Изменена логика создания аккаунтов BestBenefits

**До:**
- Аккаунт BestBenefits создавался при регистрации через email

**После:**
- Аккаунт BestBenefits **НЕ создается** при регистрации через email
- Аккаунт BestBenefits **НЕ создается** при регистрации через SMS (без email)
- Аккаунт BestBenefits создается **только после валидации email в анкете** через `/api/auth/email/verify-pin`

### 2. Условия создания аккаунта BestBenefits

Аккаунт создается автоматически, если:
- ✅ Email подтвержден (`emailVerified` не null)
- ✅ Заполнены ФИО (`firstName` и `lastName` не null)
- ✅ Аккаунт BestBenefits еще не создан (`bestBenefitsUserId` = null)

### 3. Массовая синхронизация

Создан скрипт `scripts/sync-all-users-to-bb.ts` для синхронизации всех существующих пользователей.

**Использование:**
```bash
npx tsx scripts/sync-all-users-to-bb.ts
```

**Что делает скрипт:**
- Находит всех пользователей с подтвержденным email и ФИО, но без `bestBenefitsUserId`
- Для каждого пользователя:
  - Генерирует пароль для BestBenefits (или использует сохраненный)
  - Создает аккаунт в BestBenefits
  - Сохраняет данные в БД
- Обрабатывает случай, когда пользователь уже существует в BestBenefits (использует email как ID)

## 🔄 Поток работы

### Новый пользователь (регистрация через email):
1. Регистрация → отправка кода на email
2. Подтверждение email → генерация пароля, сохранение в БД
3. **Аккаунт BestBenefits НЕ создается**
4. Заполнение анкеты (ФИО)
5. Валидация email в анкете → **создание аккаунта BestBenefits**

### Новый пользователь (регистрация через SMS):
1. Регистрация через SMS → создание пользователя без email
2. Заполнение анкеты (ФИО, email)
3. Валидация email в анкете → **создание аккаунта BestBenefits**
