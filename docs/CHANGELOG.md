# Changelog

## [1.5.0] - 2024-12-03

### ✨ Новые возможности

#### Конструктор документов
- Добавлен конструктор документов для супер-администраторов
- WYSIWYG редактор на базе TinyMCE (похож на Microsoft Word)
- Создание и редактирование HTML шаблонов документов
- Поддержка переменных вида `{{variableName}}` для подстановки данных пользователя
- Переключение между WYSIWYG и HTML режимами редактирования
- Управление шаблонами: создание, редактирование, удаление, установка по умолчанию

#### Генерация документов
- Переход с PDFKit на Puppeteer для генерации PDF
- Генерация документов из шаблонов с подстановкой переменных
- Поддержка CSS стилей в шаблонах
- Сохранение PDF в базу данных как base64

### 🔧 Улучшения

- Улучшена точность форматирования документов
- Добавлена поддержка точного выравнивания и отступов
- Улучшена обработка ошибок при генерации документов
- Оптимизирована работа с базой данных

### 🗑️ Удалено

- Удалены неиспользуемые библиотеки:
  - `@types/pdfkit`
  - `jspdf`
  - `docxtemplater`
  - `pizzip`
  - `@types/pizzip`

### 📝 Документация

- Добавлено руководство по конструктору документов
- Добавлен обзор системы
- Обновлен README с информацией о новых возможностях

### 🐛 Исправления

- Исправлена генерация PDF (переход на Puppeteer решает проблемы со шрифтами)
- Улучшена обработка ошибок в консоли браузера
- Исправлена работа с переменными в шаблонах

## [1.4.0] - Предыдущая версия

### Основные функции

- SMS и Email авторизация

- AI чат-боты с базой знаний
- Система обращений (тикеты)

## Формат версий

Версии следуют формату [Semantic Versioning](https://semver.org/):
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность с обратной совместимостью
- **PATCH** - исправления ошибок
