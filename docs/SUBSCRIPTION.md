# Подписки и тарифы (SaaS для председателей)

## Обзор

Реализована система тарифов и подписок по прайсу «Расчет цены.xlsx»: ограничение доступа по количеству участников, выбор тарифа, история платежей, продление, 14 дней теста без карты, напоминания за 7 дней и управление тарифом суперадмином.

## Модели (Prisma)

- **OrganizationSubscription** — подписка организации: статус (NONE / TRIAL / ACTIVE / EXPIRED / CANCELLED), лимит участников, тариф, даты триала/периода, ручное управление админом.
- **OrganizationPayment** — история платежей: сумма, период, статус, внешний ID (мок).
- **User.subscriptionBlockedAt** — блокировка доступа члена по лимиту подписки (последние зарегистрированные сверх лимита).

## Тарифы

Тарифы заданы в `lib/constants/tariffs.ts` по прайсу: 50, 100, 150 … 3600 участников и «Более 3600» (договорная). Периоды: месяц, квартал, полгода, год.

## API для председателя

- **GET /api/subscription** — текущая подписка, лимит, использование, доступные лицензии.
- **GET /api/subscription/plans** — список тарифов.
- **POST /api/subscription/checkout** — мок оформления подписки (body: `tariffKey`, `period`); подписка активируется сразу.
- **POST /api/subscription/trial** — активация 14 дней теста без карты.
- **GET /api/subscription/payments** — история платежей.

## Доступ членов

- В `useMembershipAccess` и профиле учтено поле **subscriptionBlockedAt**: если оно задано, член видит статус `subscription_blocked` и сообщение о приостановке доступа по лимиту подписки.
- При понижении тарифа (например, с 5000 до 1000 участников) лишние блокируются через `applyMemberLimit`: блокируются последние по дате регистрации (сверх лимита).

## Напоминания о продлении

- **GET /api/cron/subscription-reminders** — крон: за 7 дней до окончания подписки/триала отправляет председателю push и email с ссылкой на `/dashboard/subscription`.
- Вызов: с заголовком `Authorization: Bearer <CRON_SECRET>` или query `?secret=<CRON_SECRET>`, либо от Vercel Cron (`x-vercel-cron: true`). Рекомендуется вызывать раз в день.

## Суперадмин

- В карточке организации (ППО) в админке: блок **«Подписка»** (`OrgSubscriptionManage`).
- **GET/PATCH /api/admin/organizations/[id]/subscription**:
  - **activate_trial** — 14 дней теста.
  - **add_days** — добавить дни к текущему периоду (body: `days`).
  - **set_unlimited** — безлимит участников на период (body: `addDays`, по умолчанию 365).
  - **set_tariff** — задать тариф вручную (body: `tariffKey`, `memberLimit?`, `addDays`, `adminNote?`).

## Интерфейс председателя

- **Главная (дашборд)** — виджет подписки: тариф, участники/лимит, дата окончания, ссылка на раздел подписки.
- **Раздел «Подписка»** (`/dashboard/subscription`): текущая подписка, 14 дней теста без карты, выбор тарифа и периода, мок-оформление оплаты, история платежей.

## Дальнейшие шаги

1. Подключить реальную платёжную систему и заменить мок в `POST /api/subscription/checkout`.
2. Настроить вызов крона напоминаний (например, Vercel Cron или внешний cron) раз в день.
3. При необходимости — автоматически переводить подписку в EXPIRED по `periodEndsAt`/`trialEndsAt` (фоновый job) и при необходимости вызывать `applyMemberLimit` при истечении.
