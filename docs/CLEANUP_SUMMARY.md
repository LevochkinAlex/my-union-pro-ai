### 5. ✅ Создание утилитарных скриптов

#### scripts/cleanup-orphaned-documents.ts
Скрипт для очистки документов несуществующих пользователей:
- Находит документы с несуществующими userId
- Удаляет файлы документов с диска
- Удаляет записи из базы данных
- Выводит подробный отчет

**Использование:**
```bash
pnpm tsx scripts/cleanup-orphaned-documents.ts
```

#### scripts/cleanup-unused-libraries.ts
Скрипт для проверки неиспользуемых библиотек:
- Проверяет использование библиотек в коде
- Выводит список неиспользуемых библиотек
- Предлагает команду для удаления

**Использование:**
```bash
pnpm tsx scripts/cleanup-unused-libraries.ts
```
