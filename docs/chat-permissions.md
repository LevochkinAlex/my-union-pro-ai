# Разграничение прав доступа в чатах

## Обзор

Система чатов имеет четкое разграничение прав доступа между **участниками** (MEMBER) и **председателями** (PPO_HEAD). Все проверки основаны на `viewMode` пользователя.

---

## Режим участника (MEMBER)

### Доступные функции:

✅ **Личные чаты:**
- Создание и ведение личных чатов с другими участниками
- Отправка сообщений, файлов, изображений
- Редактирование и удаление своих сообщений
- Реакции на сообщения
- Пересылка сообщений в личные чаты
- Треды (threads)

✅ **Свои обращения:**
- Просмотр своих обращений (где `userId === session.user.id`)
- Отправка сообщений в чат обращения
- Закрытие обращения с рейтингом и комментарием
- Просмотр истории операций по обращению

✅ **Каналы председателя:**
- Просмотр постов в каналах
- Комментирование постов в тредах
- Реакции на посты (❤️ синхронизируется с лайком в новостях)
- Пересылка постов в личные чаты

✅ **ИИ-Ассистент:**
- Полный доступ к чату с ИИ-помощником

### Недоступные функции:

❌ **Создание групп и каналов:**
- Кнопки "Создать группу" и "Создать канал" скрыты
- API возвращает ошибку 403 при попытке создания

❌ **Создание постов в каналах:**
- Кнопка "Создать пост в канале" скрыта
- API возвращает ошибку 403 при попытке создания поста

❌ **Управление участниками:**
- Добавление участников в группы (только админы)
- Удаление участников из групп (только админы)
- Изменение ролей участников (только админы)

❌ **Управление группами:**
- Редактирование названия, описания, иконки группы (только админы)
- Архивирование чатов (только председатели)
- Очистка истории для всех (только председатели)

❌ **Табы фильтрации:**
- Табы "Все", "Рабочие", "Личные" не отображаются
- Все чаты показываются в едином списке

---

## Режим председателя (PPO_HEAD)

### Доступные функции:

✅ **Все функции участника:**
- Все функции, доступные участникам

✅ **Создание групп и каналов:**
- Создание групповых чатов
- Создание каналов (с автоматическим созданием NewsChannel)
- Управление участниками групп и каналов

✅ **Создание постов в каналах:**
- Публикация постов с заголовком, текстом, изображением
- Создание опросов (polls) в постах
- Синхронизация с разделом "Новости"

✅ **Управление группами:**
- Редактирование названия, описания, иконки
- Добавление/удаление участников
- Изменение ролей участников (admin/member)
- Архивирование чатов
- Очистка истории сообщений

✅ **Рабочие чаты:**
- Просмотр всех обращений своей организации
- Управление обращениями
- Принудительное закрытие обращений (с причиной)

✅ **Табы фильтрации:**
- Табы "Все", "Рабочие", "Личные" для удобной навигации

## Проверки прав доступа

### 1. Определение режима пользователя

**Файл:** `app/dashboard/chat/page.tsx`

```typescript
// Проверка viewMode из API
const response = await fetch("/api/user/view-mode");
const data = await safeJsonParse(response);
const viewMode = data.viewMode;

// isChairman = true только если viewMode === "PPO_HEAD"
// Даже если есть флаги isPPOHead, но viewMode === "MEMBER", то isChairman = false
setIsChairman(
  viewMode === "PPO_HEAD" || 
  viewMode === "MPO_HEAD" || 
  viewMode === "RPO_HEAD"
);
```

### 2. Фильтрация чатов

**Файл:** `app/api/chat/route.ts`

```typescript
// В режиме MEMBER показываются только:
if (isMemberMode) {
  // - Личные чаты (PRIVATE)
  // - Свои обращения (где userId === session.user.id)
  // - Каналы (CHANNEL) - для просмотра и комментирования
  // - Групповые чаты (не обращения) - скрыты
}
```

### 3. Создание групп и каналов

**Файл:** `app/api/chat/route.ts` (POST)

```typescript
// Проверка viewMode перед созданием
if (isMemberMode) {
  return NextResponse.json(
    { error: "В режиме участника нельзя создавать группы и каналы. Переключитесь в режим председателя." },
    { status: 403 }
  );
}
```

### 4. Создание постов в каналах

**Файл:** `app/api/chat/[chatId]/posts/route.ts`

```typescript
// Проверка viewMode перед созданием поста
if (isMemberMode) {
  return NextResponse.json(
    { error: "В режиме участника нельзя создавать посты в каналах. Переключитесь в режим председателя." },
    { status: 403 }
  );
}

// Дополнительная проверка: только админы канала
if (!participant || participant.role !== "admin") {
  return NextResponse.json(
    { error: "Только председатель может создавать посты в канале" },
    { status: 403 }
  );
}
```

### 5. Управление участниками

**Файл:** `app/api/chat/[chatId]/participants/route.ts`

```typescript
// Только админы могут добавлять участников
const participant = await prisma.chatParticipant.findFirst({
  where: {
    chatId,
    userId,
    role: 'admin',
    leftAt: null,
  },
});

if (!participant) {
  return NextResponse.json(
    { error: "Только админ может добавлять участников" },
    { status: 403 }
  );
}
```

## API Endpoints с проверками прав

### Создание чатов

| Endpoint | Метод | Проверка | Описание |
|----------|-------|----------|----------|
| `/api/chat` | POST | `viewMode !== "MEMBER"` | Создание групп и каналов |
| `/api/chat` | POST | Нет проверки | Создание личных чатов |

### Управление постами

| Endpoint | Метод | Проверка | Описание |
|----------|-------|----------|----------|
| `/api/chat/[chatId]/posts` | POST | `viewMode !== "MEMBER"` + `role === "admin"` | Создание постов в каналах |

### Управление участниками

| Endpoint | Метод | Проверка | Описание |
|----------|-------|----------|----------|
| `/api/chat/[chatId]/participants` | POST | `role === "admin"` | Добавление участников |
| `/api/chat/[chatId]/participants/[userId]` | DELETE | `role === "admin"` | Удаление участников |
| `/api/chat/[chatId]/participants/[userId]/role` | PATCH | `role === "admin"` | Изменение роли |

### Управление чатами

| Endpoint | Метод | Проверка | Описание |
|----------|-------|----------|----------|
| `/api/chat/[chatId]/archive` | POST | Участник чата | Архивирование (доступно всем участникам) |
| `/api/chat/[chatId]/clear` | POST | `role === "admin"` (для групп) | Очистка истории |

## UI Компоненты с проверками

### SlackStyleSidebar

- ✅ Кнопки "Создать группу" и "Создать канал" - только `isChairman`
- ✅ Табы фильтрации - только `isChairman`
- ✅ Секция "Рабочие чаты" - для председателей, "Мои обращения" - для участников

### SlackStyleChat

- ✅ Кнопка "Создать пост в канале" - только `isChairman && role === "admin"`
- ✅ Меню действий:
  - "Редактировать" - только `isCurrentUserAdmin`
  - "Архивировать" - только `isChairman && (isCurrentUserAdmin || isChannel)`
  - "Очистить историю" - только `isChairman && (isGroup ? isCurrentUserAdmin : true)`

### EmptyChatState

- ✅ Карточка "Групповые чаты" - только `isChairman`

### ChatHeader

- ✅ Кнопка "Участники" - только для групп/каналов и если есть обработчик

## Рекомендации по безопасности

1. **Всегда проверяйте `viewMode` на сервере** - не полагайтесь только на клиентские проверки
2. **Используйте `isChairman` prop** для условного рендеринга UI элементов
3. **API endpoints должны проверять права** независимо от UI
4. **Логируйте попытки несанкционированного доступа** для аудита
