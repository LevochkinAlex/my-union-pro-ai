# ✅ Исправление автоскролла чата

> **Дата:** 24 ноября 2025  
> **Проблема:** Когда бот отвечает, чат не автоматически прокручивается к его сообщению

---

## 🐛 Описание проблемы

При получении ответа от бота пользователю приходилось вручную прокручивать чат вниз, чтобы увидеть новое сообщение.

### Причина:

Логика автоскролла проверяла, находится ли пользователь внизу чата:

```typescript
// Старая логика
if (isFirstLoad || wasAtBottom) {
  // Скролл только если пользователь уже внизу
}
```

Если пользователь прокрутил чат вверх (смотрел историю), то новое сообщение бота НЕ вызывало автоскролл.

---

## ✅ Решение

Добавлена проверка: если последнее сообщение от бота, то **ВСЕГДА** скроллить вниз:

```typescript
// Проверяем, является ли последнее сообщение ответом бота
const lastMessage = messages[messages.length - 1];
const isBotResponse = lastMessage?.role === "assistant";

// Скроллим если:
// 1. Первая загрузка приложения (isFirstLoad = true)
// 2. Пользователь уже был внизу (wasAtBottom = true)
// 3. Это ответ бота (isBotResponse = true) - ВСЕГДА скроллим к ответу бота
if (isFirstLoad || wasAtBottom || isBotResponse) {
  // Скролл
}
```

## 📊 Поведение скролла

| Ситуация | Скроллится? | Почему |
|----------|-------------|--------|
| Первая загрузка чата | ✅ Да | `isFirstLoad = true` |
| Пользователь внизу → бот ответил | ✅ Да | `wasAtBottom = true` |
| Пользователь вверху → бот ответил | ✅ Да | `isBotResponse = true` (НОВОЕ!) |
| Пользователь внизу → сам отправил | ✅ Да | `wasAtBottom = true` |
| Пользователь вверху → сам отправил | ✅ Да | `isBotResponse = false`, но `shouldAutoScrollRef.current = true` |

## 💡 Особенности реализации

### Плавный скролл:
```typescript
messagesEndRef.current.scrollIntoView({ behavior: "smooth" });
```

### Гарантия отрисовки:
```typescript
requestAnimationFrame(() => {
  setTimeout(() => {
    // Скролл после полной отрисовки DOM
  }, 50);
});
```

### Защита от дублирования:
- Флаг `shouldAutoScrollRef.current` предотвращает множественные скроллы
- Сбрасывается после каждого скролла

## 🔧 Техническая информация

**React Hooks:**
- `useEffect` - отслеживание изменений массива `messages`
- `useRef` - хранение ссылки на конец списка сообщений
- `useCallback` - функция проверки позиции пользователя

**DOM API:**
- `scrollIntoView()` - прокрутка к элементу
- `requestAnimationFrame()` - синхронизация с отрисовкой
- `setTimeout()` - дополнительная задержка для гарантии
