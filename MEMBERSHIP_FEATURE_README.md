# Функционал "Членство в профсоюзе"

## Описание

Добавлена новая вкладка "Членство" в профиле пользователя с системной информацией о профсоюзном членстве.

## Что реализовано

### 1. База данных

Добавлены новые поля в модель `User`:
- `unionCardNumber` - Номер профсоюзной карточки (16-значный код формата XXXX XXXX XXXX XXXX)
- `membershipJoinedAt` - Дата вступления в профсоюз
- `membershipStatus` - Статус членства (ACCEPTED, NOT_ACCEPTED, REMOVED)

Создана новая модель `MembershipHistory` для журналирования истории членства:
- История переходов между организациями
- Статусы (ACCEPTED, REMOVED, TRANSFERRED)
- Даты изменений
- Заметки

Добавлены новые типы документов:
- `MEMBERSHIP_REMOVAL_APPLICATION` - Заявление о снятии с учета
- `MEMBERSHIP_TRANSFER_APPLICATION` - Заявление о переходе в другой профсоюз

### 2. API Endpoints

#### GET `/api/profile/membership`
Получает информацию о членстве пользователя:
- Номер профсоюзной карточки (генерируется автоматически, если отсутствует)
- Статус членства
- Текущая организация
- История членства

#### POST `/api/profile/membership/generate-removal`
Генерирует заявление о снятии с учета:
- Создает PDF документ
- Сохраняет в базу данных
- Записывает в историю членства

#### POST `/api/profile/membership/generate-transfer`
Генерирует заявление о переходе в другой профсоюз:
- Создает PDF документ
- Сохраняет в базу данных
- Записывает в историю членства

### 3. Генерация PDF документов

Созданы функции генерации PDF:
- `generateMembershipRemovalApplication` - Заявление о снятии с учета
- `generateMembershipTransferApplication` - Заявление о переходе

Все данные автоматически подтягиваются из профиля пользователя.

### 4. UI - Вкладка "Членство"

В профиле добавлена новая вкладка "Членство" с отображением:
- Номера профсоюзной карточки
- Статуса членства (Принят на учет / Снят с учета / Пока не принят)
- Даты вступления (если принят)
- Текущей организации
- Истории членства (журналирование всех переходов)

Кнопки действий (доступны только для членов профсоюза):
- "Снять с учета" - генерирует заявление о снятии с учета
- "Перейти в другой профсоюз" - генерирует заявление о переходе

## Установка

### 1. Выполните миграцию базы данных

```bash
npx prisma migrate dev --name add_membership_fields
```

Или используйте SQL файл из `prisma/migrations/MIGRATION_MEMBERSHIP_FIELDS.sql`

### 2. Обновите Prisma Client

```bash
npx prisma generate
```

### 3. Перезапустите приложение

Все готово к использованию!

## Использование

1. Откройте профиль пользователя
2. Перейдите на вкладку "Членство"
3. Номер профсоюзной карточки будет автоматически сгенерирован при первом открытии
4. Для членов профсоюза доступны кнопки генерации заявлений
5. Сгенерированные заявления автоматически добавляются в раздел "Документы"

## Примечания

- Номер профсоюзной карточки генерируется автоматически при первом обращении к API
- Все данные в заявлениях подтягиваются из профиля пользователя
- История членства ведется автоматически при генерации заявлений
- Статус членства можно обновлять через админ-панель (функционал для будущей реализации)
