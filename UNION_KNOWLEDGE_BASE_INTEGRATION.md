# Интеграция базы знаний профсоюза

## Обзор

Документы профсоюза находятся в папке `public/docs/union/`. Для интеграции с чат-ботом их нужно загрузить в систему управления базой знаний.

## Документы профсоюза

Доступные документы:
- Устав Профсоюза (принят на VII съезде апрель 2021)
- Положение ПДК ЦК Профсоюза
- Положение о Профбюро и профгруппе ППО Профсоюза
- Положение о ШПА
- Положение о порядке приема в Профсоюз
- Положение о порядке уплаты членских профвзносов
- Памятка по делопроизводству
- Методическое пособие по организации финансовой деятельности в ППО
- Общее положение о контрольно-ревизионных органах Профсоюза
- Методические рекомендации по обработке персональных данных
- Концепция кадровой политики
- Концепция по обучению профкадров и актива
- Инструкция о порядке учета членов Профсоюза в ППО
- Брошюры по персональным данным
- Брошюра ШПА
- Общее положение о ППО Профсоюза

## Шаги интеграции

### 1. Создать базу знаний

1. Перейдите в админ-панель: `https://myunion.pro/admin/ai-chat`
2. Перейдите на вкладку "Базы знаний"
3. Нажмите "Создать базу знаний"
4. Заполните:
   - **Название**: "База знаний профсоюза работников здравоохранения РФ"
   - **Описание**: "Устав, положения, регламенты и методические материалы профсоюза"
5. Нажмите "Создать"

### 2. Загрузить документы

1. Откройте созданную базу знаний
2. Загрузите каждый документ из папки `public/docs/union/`:
   - Нажмите "Загрузить файл"
   - Выберите документ
   - Дождитесь обработки (статус "COMPLETED")
3. Система автоматически:
   - Извлечет текст из документов
   - Разобьет на фрагменты (chunks)
   - Создаст векторные embeddings для семантического поиска

### 3. Подключить к боту

1. Перейдите на вкладку "Боты"
2. Откройте бота "Statement Bot" (бот по умолчанию для чата заявлений)
3. В разделе "Базы знаний" выберите "База знаний профсоюза работников здравоохранения РФ"
4. Сохраните изменения

### 4. Настроить бота для обращений

1. Откройте бота "Appeal Bot" (бот для обращений)
2. В разделе "Базы знаний" выберите "База знаний профсоюза работников здравоохранения РФ"
3. Сохраните изменения

## Как это работает

После интеграции базы знаний:

1. **После генерации заявления** пользователь может задавать вопросы о профсоюзе
2. **Чат-бот использует RAG (Retrieval-Augmented Generation)**:
   - При получении вопроса создается embedding вопроса
   - Ищутся похожие фрагменты в базе знаний (по cosine similarity)
   - Релевантные фрагменты добавляются в контекст для AI
   - AI отвечает на основе найденных документов

3. **Примеры вопросов**:
   - "Какие права и обязанности у членов профсоюза?"
   - "Кто является председателем профсоюза?"
   - "Как составить обращение в профсоюз?"
   - "Какой размер членских взносов?"
   - "Как происходит прием в профсоюз?"

## Мониторинг

Проверьте работу в логах:
```bash
pm2 logs my-union-pro | grep "knowledge"
```

Должны появляться строки типа:
```
[chat] Актуальные материалы (используй их как факты):
[1] База знаний профсоюза (релевантность 0.85):
[содержимое фрагмента]
```

## Обновление документов

Если документы обновляются:
1. Загрузите новую версию в базу знаний
2. Старая версия автоматически перезапишется
3. Embeddings пересоздадутся автоматически

## Настройка релевантности

В функции `retrieveRelevantChunks` (`app/api/chat/route.ts`):
- **Порог similarity**: 0.7 (можно изменить для большей/меньшей точности)
- **Количество фрагментов**: 5 (можно увеличить для более подробных ответов)

## Производительность

- Векторный поиск работает быстро (< 100ms)
- Кэширование embeddings в БД
- Используется cosine similarity для поиска
- Поддержка многомиллионных баз знаний

## Безопасность

- Доступ к базам знаний только через админ-панель
- Пользователи не видят исходные документы
- AI использует только релевантные фрагменты
- Логирование всех обращений к базе знаний
