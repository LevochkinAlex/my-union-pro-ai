# Руководство по использованию функции имперсонализации

## 📋 Обзор

Функция имперсонализации позволяет супер-админам просматривать личный кабинет пользователя от его имени для оказания быстрой поддержки.

## 🚀 Как войти в режим имперсонализации

1. Перейдите в админ-панель: `/admin/users`
2. Найдите нужного пользователя в списке
3. Нажмите кнопку **"Войти от имени"** в колонке "Действия"
4. Вы автоматически перейдете в личный кабинет пользователя

## 🚪 Как выйти из режима имперсонализации

### Способ 1: Через баннер (рекомендуется)

В режиме имперсонализации в верхней части страницы отображается **желтый баннер** с предупреждением:

```
⚠️ Режим просмотра: Вы просматриваете личный кабинет от имени пользователя
[Вернуться в админ-панель]
```

**Нажмите кнопку "Вернуться в админ-панель"** - вы автоматически вернетесь в админ-панель с вашей обычной сессией.

### Способ 2: Прямой переход

Вы также можете вручную перейти по адресу `/admin/users` или `/admin/dashboard` - система автоматически восстановит вашу сессию админа.

## 🎨 Визуальные индикаторы

### Баннер имперсонализации

- **Цвет**: Желтый фон (`bg-yellow-500`)
- **Расположение**: Верхняя часть страницы (sticky)
- **Содержимое**: 
  - Иконка предупреждения
  - Текст о режиме просмотра
  - Кнопка "Вернуться в админ-панель"

### Поведение баннера

- Баннер отображается **только** в режиме имперсонализации
- Баннер **всегда виден** вверху страницы (sticky positioning)
- Баннер скрывается автоматически после выхода из режима

## 🔒 Безопасность

### Ограничения доступа

- Только пользователи с ролью `SUPER_ADMIN` могут использовать имперсонализацию
- ID оригинального админа сохраняется в сессии для безопасного восстановления
- Восстановление сессии возможно только для того же админа, который начал имперсонализацию

### Проверки безопасности

1. **При входе в режим имперсонализации:**
   - Проверяется, что текущий пользователь - супер-админ
   - Сохраняется ID оригинального админа в сессии

2. **При выходе из режима:**
   - Проверяется, что ID админа совпадает с сохраненным
   - Проверяется, что админ все еще является супер-админом
   - Восстанавливается оригинальная сессия админа

## 📁 Технические детали

### Компоненты

- **`components/admin/ImpersonateButton.tsx`** - Кнопка для входа в режим имперсонализации
- **`components/admin/ImpersonationBanner.tsx`** - Баннер с кнопкой выхода
- **`app/api/admin/users/[id]/impersonate/route.ts`** - API endpoint для входа
- **`app/api/admin/impersonate/restore/route.ts`** - API endpoint для выхода

### Провайдеры NextAuth

- **`impersonate`** - Провайдер для входа в режим имперсонализации
- **`restore-admin`** - Провайдер для восстановления сессии админа

### Структура сессии

В режиме имперсонализации в сессии хранятся:

```typescript
{
  user: {
    id: "user_id", // ID пользователя, от имени которого просматривается кабинет
    isImpersonating: true,
    originalAdminId: "admin_id" // ID админа, который начал имперсонализацию
  }
}
```

## 🐛 Решение проблем

### Баннер не отображается

1. Проверьте, что вы действительно в режиме имперсонализации
2. Проверьте консоль браузера на наличие ошибок
3. Убедитесь, что `session.user.isImpersonating === true`

### Кнопка "Вернуться в админ-панель" не работает

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что `session.user.originalAdminId` существует
3. Проверьте, что админ все еще является супер-админом

### Не могу выйти из режима

1. Попробуйте перейти напрямую на `/admin/users`
2. Очистите cookies и войдите заново
3. Проверьте логи сервера на наличие ошибок

## 📝 Примеры использования

### Вход в режим имперсонализации

```typescript
// В компоненте ImpersonateButton
const handleImpersonate = async () => {
  const result = await signIn("impersonate", {
    userId: user.id,
    originalAdminId: session.user.id,
    redirect: false,
  });
  
  if (result?.ok) {
    router.push("/dashboard");
  }
};
```

### Выход из режима имперсонализации

```typescript
// В компоненте ImpersonationBanner
const handleStopImpersonation = async () => {
  const result = await signIn("restore-admin", {
    adminId: session.user.originalAdminId,
    restoreToken: "restore",
    redirect: false,
  });
  
  if (result?.ok) {
    window.location.href = "/admin/users";
  }
};
```

## ✅ Чеклист проверки

При тестировании функции имперсонализации проверьте:

- [ ] Супер-админ может войти в режим имперсонализации
- [ ] Баннер отображается в режиме имперсонализации
- [ ] Кнопка "Вернуться в админ-панель" работает
- [ ] После выхода сессия админа восстанавливается
- [ ] Обычные пользователи не могут использовать имперсонализацию
- [ ] Баннер скрывается после выхода из режима
- [ ] Редирект в админ-панель работает корректно
