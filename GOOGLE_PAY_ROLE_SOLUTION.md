# 🔐 Решение проблемы с ролью Google Pay API Admin

## Важно!

Роль **"Google Pay API Admin"** может не существовать или называться по-другому. 

## ✅ Хорошая новость!

У вашего Service Account уже есть роль **"Service Account Token Creator"**, которая должна быть достаточной для работы с Google Wallet API!

## Почему это должно работать:

В нашем коде мы используем JWT с scope `https://www.googleapis.com/auth/wallet_object.issuer`, и роль "Service Account Token Creator" позволяет создавать токены для этого scope.

## Что делать:

### 1. Попробуйте использовать существующие права

Роль **"Service Account Token Creator"** уже должна быть достаточной. Давайте протестируем:

1. Убедитесь что:
   - ✅ Google Wallet API включен
   - ✅ `GOOGLE_PAY_ISSUER_ID=3388000000023063666` в `.env.local`
   - ✅ Business Profile одобрен

2. Перезапустите сервер:
   ```bash
   pnpm dev
   ```

3. Попробуйте использовать функцию "Скачать" на Android устройстве

### 2. Если получите ошибку 403

Если API вернет ошибку 403 (Forbidden), попробуйте добавить одну из этих ролей (если найдете):

- **"Owner"** (временная, только для теста, потом убрать)
- Или любую роль связанную с **"Wallet"**
- Или **"Service Account User"** (если ещё нет)

### 3. Альтернативные роли для поиска

В диалоге добавления ролей попробуйте поискать:
- **"Wallet"**
- **"Object"**
- **"Service Account"**

Но скорее всего текущих прав будет достаточно!

## Проверка работы:

После настройки попробуйте:
1. Открыть приложение на Android
2. Перейти в "Мои скидки"
3. Нажать "Скачать"
4. Проверить логи сервера на наличие ошибок

Если всё работает - отлично! Если ошибка 403 - тогда добавим дополнительные роли.
