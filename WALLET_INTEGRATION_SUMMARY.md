## 🔄 Логика работы по платформам

### Desktop (Windows, macOS, Linux)
**Функция:** `downloadAsPDF()`
- ✅ Конвертирует PNG в PDF через jsPDF
- ✅ Открывает PDF в новой вкладке браузера
- ✅ Fallback: открывает изображение в новой вкладке

### Android
**Функция:** `downloadForGoogleWallet()`
- ✅ Отправляет запрос на `/api/wallet/google-pass`
- ✅ Если успешно → открывает `https://pay.google.com/gp/v/save/{jwt}`
- ✅ Если API не настроен (501) → скачивает PNG
- ✅ Если ошибка → скачивает PNG

**Требования:**
- ✅ Google Wallet API включен
- ✅ `GOOGLE_PAY_ISSUER_ID=3388000000023063666` в `.env.local`
- ✅ Service Account с правами (текущие должны работать)
- ✅ Business Profile одобрен ✅

### iOS (iPhone, iPad)
**Функция:** `downloadForAppleWallet()`
- ✅ Отправляет запрос на `/api/wallet/apple-pass`
- ⚠️ Если API не настроен (501) → скачивает PNG
- ⚠️ Если ошибка → скачивает PNG
- ⚠️ Для полноценной работы нужны сертификаты Apple

**Текущий статус:** API endpoint возвращает 501 (Not Implemented)
**Fallback:** Скачивание PNG изображения
