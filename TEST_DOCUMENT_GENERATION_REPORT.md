- ✅ `/api/documents/regenerate` - перегенерация документов
- ✅ `/api/profile` - получение статуса профиля (включая `profileChangedAfterDocuments`)

### Логика работы:
1. При генерации документов:
   - Проверяется полнота профиля
   - Загружаются шаблоны по умолчанию
   - Извлекаются переменные из данных пользователя
   - Рендерятся HTML шаблоны
   - Генерируются PDF документы
   - Сохраняются в БД с привязкой к шаблону
   - Сбрасывается флаг `profileChangedAfterDocuments`

2. При изменении профиля:
   - Проверяется наличие сгенерированных документов
   - Если документы есть и профиль изменился → устанавливается `profileChangedAfterDocuments = true`
   - Обновляется `profileLastModified`

3. При перегенерации:
   - Удаляются старые документы со статусом GENERATED/DRAFT
   - Генерируются новые документы
   - Сбрасывается флаг `profileChangedAfterDocuments`
