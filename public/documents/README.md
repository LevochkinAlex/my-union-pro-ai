# Статичные документы

Эта папка содержит статичные документы профсоюза, доступные всем пользователям для ознакомления.

## Файлы:

- **union-charter.docx** - Устав Профсоюза работников здравоохранения РФ (принят на VII съезде, апрель 2021)

## Примечание:

Для лучшей совместимости рекомендуется конвертировать DOCX файлы в PDF формат.

### Конвертация в PDF (macOS):

```bash
# Используя LibreOffice (если установлен)
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf union-charter.docx --outdir .
```

### Конвертация в PDF (Linux):

```bash
libreoffice --headless --convert-to pdf union-charter.docx
```
