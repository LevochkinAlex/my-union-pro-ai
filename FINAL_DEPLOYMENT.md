# 🚀 МойСоюз v1.5.0 - Финальный деплой

## ✅ Что реализовано

### 2FA через Telegram Bot

**Единственный канал:** Telegram 📱

**Почему только Telegram:**
- ✅ **Полностью бесплатно** - без лимитов и абонентской платы
- ✅ **Мгновенная доставка** - PIN-коды приходят за 1-2 секунды
- ✅ **Популярен в России** - 70%+ взрослого населения
- ✅ **Простая интеграция** - работает из коробки
- ✅ **Надежно** - официальный Telegram Bot API

**WhatsApp отклонен:**
- ❌ SendPulse WhatsApp требует предварительно одобренные шаблоны от Facebook
- ❌ Нельзя отправлять произвольный текст с PIN-кодами
- ❌ Подходит только для маркетинговых рассылок, не для транзакционных сообщений

**SMS отключен:**
- ❌ Слишком дорого (~4 руб/SMS)
- ❌ Не нужен при наличии Telegram

## 📋 Checklist деплоя

### 1️⃣ Переменные окружения

Добавьте в `.env` на продакшене:

```env
# Telegram Bot (единственный канал для 2FA)
# ⚠️ ВАЖНО: Используйте переменные окружения для токенов!
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
TELEGRAM_BOT_USERNAME=myunionpro_bot
```

**Не нужны:**
- ~~SENDPULSE_USER_ID~~ - удалено
- ~~SENDPULSE_SECRET~~ - удалено
- ~~SENDPULSE_WHATSAPP_BOT_ID~~ - удалено

- Добавлено: `User.telegramUsername` (опционально, для справки)

### 3️⃣ Деплой кода

### 4️⃣ Настройка Telegram Webhook (после деплоя!)

**Важно:** Webhook настраивается **ПОСЛЕ** деплоя на продакшен!

```bash
# ⚠️ ВАЖНО: Замените YOUR_TELEGRAM_BOT_TOKEN на реальный токен из переменных окружения
curl -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook" \
  -d "url=https://myunion.pro/api/telegram/webhook"
```

**Проверка webhook:**

```bash
# ⚠️ ВАЖНО: Замените YOUR_TELEGRAM_BOT_TOKEN на реальный токен из переменных окружения
curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/getWebhookInfo"
```

**Ожидаемый ответ:**
```json
{
  "ok": true,
  "result": {
    "url": "https://myunion.pro/api/telegram/webhook",
    "has_custom_certificate": false,
    "pending_update_count": 0
  }
}
```

## 🧪 Тестирование

### Сценарий 1: Новый пользователь (первый вход)

1. Откройте `https://myunion.pro/login`
2. Введите номер телефона
3. Нажмите "Получить код"
4. **Результат:** Показывается кнопка "Привязать Telegram"
5. Нажмите кнопку → откроется `@myunionpro_bot`
6. Нажмите `/start` в боте
7. **Результат:** "Telegram успешно привязан!"
8. Вернитесь на сайт, снова нажмите "Получить код"
9. **Результат:** PIN-код приходит в Telegram за 1-2 секунды
10. Введите код → вход выполнен ✅

**Время:** ~30 секунд (включая привязку)

## 🔧 Troubleshooting

### Проблема 1: PIN-код не приходит

**Проверьте:**

```bash
# 1. Webhook настроен?
curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/getWebhookInfo"

# 2. Логи сервера
docker logs -f myunion-app | grep "2FA Auth"

# 3. Пользователь не заблокировал бота?
# Пользователь должен нажать /start в боте
```

**Решение:**
1. Если webhook не настроен → настроить
2. Если webhook настроен, но URL неправильный → перенастроить
3. Если пользователь заблокировал бота → попросить разблокировать

---

### Проблема 2: Кнопка "Привязать Telegram" не работает

**Причина:** Неправильный `TELEGRAM_BOT_USERNAME`

**Решение:**
```bash
# Проверьте переменную окружения
echo $TELEGRAM_BOT_USERNAME
# Должно быть: myunionpro_bot

# Если неправильно, обновите .env и перезапустите
```

---

### Проблема 3: Webhook возвращает 404

**Причина:** API endpoint недоступен

**Решение:**
```bash
# Проверьте, что сайт задеплоен
curl https://myunion.pro/api/telegram/webhook

# Должен вернуть: {"status":"ok","message":"Telegram webhook is ready"}
```

## 📚 API Endpoints

### `POST /api/auth/sms/send-pin`

**Request:**
```json
{
  "phone": "+79991234567"
}
```

**Response (Telegram привязан):**
```json
{
  "success": true,
  "deliveryMethod": "telegram",
  "message": "Код подтверждения отправлен в Telegram 📱"
}
```

**Response (Telegram НЕ привязан):**
```json
{
  "error": "Telegram не привязан",
  "requiresTelegram": true,
  "message": "Для получения кода подтверждения необходимо привязать Telegram",
  "helpText": "Это займет всего 20 секунд! Telegram обеспечивает мгновенное и безопасное получение кодов.",
  "phone": "+79991234567"
}
```

### `POST /api/telegram/link`

**Request:**
```json
{
  "phone": "+79991234567"
}
```

**Response:**
```json
{
  "success": true,
  "deepLink": "https://t.me/myunionpro_bot?start=AUTH_phone_+79991234567",
  "botUsername": "myunionpro_bot"
}
```

### `GET /api/telegram/link/status?phone=+79991234567`

**Response:**
```json
{
  "linked": true,
  "telegramUsername": "username"
}
```
