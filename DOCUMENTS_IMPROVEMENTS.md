# Улучшения системы документов

## Дата: 24 ноября 2025

### Проблемы, которые были исправлены:

#### 1. Отсутствие размера файла устава
**Проблема:** Для документа "Устав Профсоюза работников здравоохранения РФ" не отображался размер файла (показывалось "Размер: —").

**Причина:** При создании документа устава в процессе регистрации нового пользователя не вычислялся и не сохранялся размер файла.

**Решение:**
- Обновлен файл `app/api/auth/register/verify-code/route.ts`:
  - Добавлен импорт модулей `fs` и `path`
  - Добавлено вычисление размера файла устава перед созданием записи в БД
  - Теперь при создании документа устава поле `fileSize` заполняется корректно

**Размер файла устава:** 100,201 байт (97.9 КБ)

#### 2. Неправильная сортировка документов
**Проблема:** Документы в разделе "Мои документы" сортировались только по дате создания (новые сверху), без учета приоритета типа документа.

**Желаемое поведение:** 
1. Сначала заявления (важные документы для вступления в профсоюз)
2. Потом обращения
3. Затем прочие документы (устав и другие)

**Решение:**
- Обновлен файл `app/api/documents/route.ts`:
  - Добавлена логика приоритетной сортировки по типу документа
  - Приоритеты:
    1. `MEMBERSHIP_APPLICATION` (Заявление о вступлении в профсоюз) - приоритет 1
    2. `CONTRIBUTION_APPLICATION` (Заявление о взносах) - приоритет 2
    3. `APPEAL` (Обращения) - приоритет 3
    4. `OTHER` (Устав и прочие) - приоритет 4
  - В рамках каждой группы документы сортируются по дате создания (новые сверху)

### Миграция данных

Создан скрипт для обновления размера файла устава для существующих пользователей:
- **Файл:** `scripts/update-charter-file-size.ts`
- **Запуск:** `pnpm tsx scripts/update-charter-file-size.ts`
- **Результаты:** Обновлено 6 документов устава для существующих пользователей

### Порядок отображения документов после исправления

Теперь в разделе "Мои документы" документы отображаются в следующем порядке:

1. **Заявление о вступлении в профсоюз** (тип: MEMBERSHIP_APPLICATION)
   - Статус: Сгенерирован
   - Размер: ~20 КБ

2. **Заявление о взносах** (тип: CONTRIBUTION_APPLICATION)
   - Статус: Сгенерирован
   - Размер: ~19 КБ

3. **Устав Профсоюза работников здравоохранения РФ** (тип: OTHER)
   - Статус: Сгенерирован
   - Размер: ~98 КБ ✅ (теперь отображается корректно)
