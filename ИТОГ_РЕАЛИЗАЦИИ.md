## 🎯 Что было реализовано

### 1. ✅ Две кнопки после генерации документов

**Где:** Чат AI после завершения профиля

**Кнопки:**
- 📥 **Скачать документы** - открывает раздел документов
- 👤 **Проверить профиль** - открывает страницу профиля

**Файл:** `components/chat/Chat.tsx`

---

### 2. ✅ Механизм отслеживания изменений профиля

**Что добавлено в БД:**
- `profileChangedAfterDocuments` (Boolean) - флаг изменения
- `profileLastModified` (DateTime) - дата изменения

**Отслеживаемые поля:**
- ФИО, дата рождения, телефон, адрес
- Должность, профессия, образование

**Логика:**
- При изменении любого из этих полей → флаг = true
- Только если у пользователя уже есть документы
- Не критичные поля (аватар, хобби) НЕ вызывают флаг

**Файлы:**
- `prisma/schema.prisma`
- `app/api/profile/route.ts`

---

### 3. ✅ Баннер в разделе "Документы"

**Когда показывается:**
- Когда `profileChangedAfterDocuments = true`
- То есть после изменения данных профиля

**Что содержит:**
- ⚠️ Предупреждение об изменении данных
- 📝 Объяснение зачем нужна перегенерация
- 🔄 Кнопка "Перегенерировать документы"
- 👤 Кнопка "Проверить профиль"

**Дизайн:**
- Цвет: Оранжевый (предупреждение)
- Адаптивный (mobile + desktop)
- Красивые иконки и анимации

**Файл:** `app/dashboard/documents/page.tsx`

---

### 4. ✅ API перегенерации документов

**Endpoint:** `POST /api/documents/regenerate`

**Что делает:**
1. Проверяет авторизацию
2. Проверяет полноту профиля
3. Генерирует новые PDF с актуальными данными
4. Обновляет документы в БД
5. Сбрасывает флаг `profileChangedAfterDocuments = false`

**Безопасность:**
- Требует авторизации
- Подтверждение перед перегенерацией
- Валидация данных
- Логирование

**Файл:** `app/api/documents/regenerate/route.ts`
