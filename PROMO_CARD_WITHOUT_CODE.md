# Генератор карточек с/без промокода

## Реализованный функционал

Генератор карточек теперь работает в **двух режимах**:

### 🎫 Режим 1: С промокодом

**Когда:** У скидки есть активированный промокод (после нажатия "Использовать")

**Что отображается:**
- ✅ QR-код для сканирования (200x200px)
- ✅ Промокод крупными буквами в цветной рамке
- ✅ Название скидки (1 строка)
- ✅ Логотип MyUnion
- ✅ ФИО пользователя
- ✅ Срок действия (если указан)

**Пример:** Domino's Pizza с промокодом `BESTBENEFITS`

---

### 🖼️ Режим 2: Без промокода (НОВЫЙ!)

**Когда:** У скидки нет промокода (не активирована или промокод не предусмотрен)

**Что отображается:**
- ✅ Картинка скидки/партнера (200x200px, если есть)
- ✅ Название скидки (до 2 строк с переносом)
- ✅ Краткое описание условий (до 4 строк)
- ✅ Логотип MyUnion
- ✅ ФИО пользователя
- ✅ Срок действия (если указан)
- ❌ **БЕЗ** QR-кода
- ❌ **БЕЗ** промокода

**Пример:** САМОКАТ (не активирована)

## Технические детали

### Интерфейс `PromoCardData`

```typescript
interface PromoCardData {
  promoCode?: string;           // Опционально!
  userName: string;
  discountName: string;
  discountDescription?: string; // Для режима без промокода
  imageUrl?: string;            // Картинка скидки
  validUntil?: Date;
}
```

```typescript
  if (imageUrl) {
    // Загружаем и рисуем картинку скидки
  }
  if (discountDescription) {
    // Рисуем описание с переносом строк
  }

```

### Вызов из компонента

```typescript
const handleDownloadPromoCard = async (discount: DiscountItem) => {
  const blob = await generatePromoCard({
    promoCode: discount.promoCode,         // может быть undefined
    userName: "Иван Иванов",
    discountName: discount.title,
    discountDescription: discount.shortDescription,
    imageUrl: discount.imageUrl,
    validUntil: discount.validUntil ? new Date(discount.validUntil) : undefined,
  });
  
  // Скачиваем файл
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = `promo-card-${discount.id}.png`;
  a.click();
};
```

## Дизайн карточек

### Общие элементы (оба режима)
- 🎨 Градиентный фиолетовый фон (#667eea → #764ba2)
- 📄 Белая карточка с тенью (1120x550px)
- 🏷️ Логотип MyUnion (верхний левый угол)
- 👤 ФИО пользователя (внизу слева)
- ⏰ Срок действия (внизу слева, под ФИО)

### Режим с промокодом
- 📱 QR-код 200x200px (правый верхний угол)
- 🔤 Промокод в светло-сером боксе с фиолетовой рамкой
- 📏 Название скидки - 1 строка с обрезкой

### Режим без промокода
- 🖼️ Картинка скидки 200x200px (правый верхний угол, закругленные углы)
- 📝 Название скидки - до 2 строк с переносом
- 📄 Описание условий - до 4 строк с переносом

## Кнопка "Скачать"

### Раньше ❌
```typescript
disabled={!discount.promoCode || downloading === discount.id}
```
- Кнопка заблокирована без промокода
- Пользователь не может скачать карточку

### Теперь ✅
```typescript
disabled={downloading === discount.id}
```
- Кнопка всегда активна (если не идет загрузка)
- Генератор автоматически выбирает режим

## FAQ

**Q: Почему кнопка "Скачать" была заблокирована?**
A: Раньше генератор требовал промокод для создания QR-кода. Теперь есть альтернативный режим без промокода.

**Q: Можно ли скачать карточку для любой скидки?**
A: Да! Теперь для всех активированных скидок (на странице "Мои скидки") кнопка всегда активна.

**Q: Что если нет ни промокода, ни картинки, ни описания?**
A: Карточка все равно сгенерируется с названием скидки, логотипом MyUnion и данными пользователя.

**Q: Можно ли распечатать карточку?**
A: Да, PNG формат подходит для печати. Размер 1200x630px (~10x5 см в высоком качестве).

**Q: Как работает перенос текста?**
A: Функция `wrapText()` автоматически разбивает длинный текст на строки по максимальной ширине.
