# 🧹 Сброс данных пользователя

Скрипт для полной очистки данных пользователя без удаления аккаунта. Полезен для тестирования бота.

## Что делает скрипт

1. ✅ **Удаляет все сообщения чата**
2. ✅ **Удаляет все сессии чата**
3. ✅ **Удаляет все документы пользователя**
4. ✅ **Очищает профиль** (ФИО, дата рождения, адрес, должность, профессия и т.д.)
5. ✅ **Сохраняет аккаунт** (email, пароль, роль)

## Использование

### Вариант 1: Через npm скрипт (рекомендуется)

```bash
pnpm reset-user <email>
```

**Пример:**
```bash
pnpm reset-user ceo@yappix.ru
```

### Вариант 2: Напрямую через tsx

```bash
pnpm tsx scripts/reset-user-data.ts <email>
```

## После сброса

Пользователь может войти с тем же email и паролем, но все данные профиля и истории чата будут удалены. Бот начнет диалог с начала.

## Безопасность

⚠️ **ВНИМАНИЕ:** Операция необратима! Все данные пользователя будут удалены без возможности восстановления.

## Что НЕ удаляется

- Email пользователя
- Пароль
- Роль в системе
- Статус членства
- Дата создания аккаунта
