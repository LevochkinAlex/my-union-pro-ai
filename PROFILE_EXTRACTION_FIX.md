# Исправление извлечения данных профиля из чата

## Дата: 24 ноября 2025

### Проблема

Пользователь сообщил, что чат показывает "Профиль заполнен!" **до того, как он ответил на все вопросы**.

#### Ситуация:
- Пользователь дошел только до вопроса: "Теперь, пожалуйста, напишите ваш уровень образования. Доступные варианты:"
- Но система уже показала маркер `[PROFILE_COMPLETE]` и блок "Профиль заполнен!"
- В профиле автоматически заполнились:
  - **Образование:** "Начальное общее" (взято из списка вариантов бота!)
  - **Должность:** "должность на работе" (некорректное значение)
  - **Профессия:** "должность на работе" (некорректное значение)

#### Корневая причина:

Функция `extractProfileDataFromMessages` в `lib/profile-extraction.ts` извлекала данные **из всех сообщений**, включая сообщения бота.

Когда бот писал:
> "Теперь, пожалуйста, напишите ваш уровень образования. Доступные варианты: - **Начальное общее** - Основное общее..."

Система находила "Начальное общее" в **списке вариантов** и записывала его как образование пользователя!

### Техническая детализация

#### Проблемный код (было):

```typescript:216:218:lib/profile-extraction.ts
// Join all text for analysis (fallback если структурированные данные не найдены)
const allText = messages
  .map((msg) => msg.content)
  .join("\n");
```

Затем для извлечения образования использовался `allText`:

```typescript:580:587:lib/profile-extraction.ts
if (!profileData.education) {
  const educationPattern =
    /(высшее|среднее|начальное|бакалавриат|магистратура|специалитет|аспирантура|среднее профессиональное|начальное профессиональное).+?(?=\.|\n|$)/i;
  const educationMatch = allText.match(educationPattern);
  if (educationMatch) {
    profileData.education = educationMatch[0].trim();
  }
}
```

Этот регулярное выражение находило **любое упоминание** слов "начальное", "среднее", "высшее" во **ВСЁМ тексте**, включая списки вариантов, которые перечислял бот!

Аналогичная проблема была с извлечением должности и профессии.

### Решение

**1. Разделили извлечение на два источника:**

- **Структурированные данные** (из сообщений бота, когда он перечисляет собранную информацию): `allText`
- **Fallback-извлечение** (для данных, которые не были найдены в структурированном виде): `userOnlyText`

**2. Создали отдельный текст только из сообщений пользователя:**

```typescript:215:226:lib/profile-extraction.ts
// Join all text for analysis (fallback если структурированные данные не найдены)
// ⚠️ ВАЖНО: Для fallback используем ТОЛЬКО сообщения пользователя,
// чтобы избежать извлечения данных из списков вариантов, которые перечисляет бот
const allText = messages
  .map((msg) => msg.content)
  .join("\n");

// Для fallback-извлечения используем только сообщения пользователя
const userOnlyText = messages
  .filter((msg) => msg.role === "user")
  .map((msg) => msg.content)
  .join("\n");
```

**3. Заменили `allText` на `userOnlyText` в fallback-паттернах:**

- Образование (education)
- Должность (jobTitle)
- Профессия (profession)

Пример исправления для образования:

```typescript:577:593:lib/profile-extraction.ts
// Extract education - только если не извлечено из структурированных данных
if (!profileData.education && !hasStructuredData) {
  // Используем userOnlyText чтобы не извлекать из списков вариантов бота
  const educationLabelPattern = /(?:\*\*Образование\*\*|Образование)[^:\n]*[:\-–]\s*(.+)/i;
  const educationLabelMatch = userOnlyText.match(educationLabelPattern);

  if (educationLabelMatch) {
    profileData.education = educationLabelMatch[1].split(/\n/)[0].trim();
  }

  if (!profileData.education) {
    const educationPattern =
      /(высшее|среднее|начальное|бакалавриат|магистратура|специалитет|аспирантура|среднее профессиональное|начальное профессиональное).+?(?=\.|\n|$)/i;
    const educationMatch = userOnlyText.match(educationPattern); // ✅ Теперь userOnlyText
    if (educationMatch) {
      profileData.education = educationMatch[0].trim();
    }
  }
}
```

### Измененные файлы

1. **`lib/profile-extraction.ts`**

   - Заменено использование `allText` на `userOnlyText` в паттернах для:

     - Должности (jobTitle)

### Рекомендации на будущее

1. **Всегда разделяйте источники данных:**
   - Структурированные данные от бота (когда он подтверждает собранную информацию)
   - Ответы пользователя (для fallback-извлечения)

2. **Избегайте извлечения из контекста вопросов:**
   - Не извлекайте данные из списков вариантов
   - Не извлекайте из текста подсказок и инструкций

3. **Логируйте процесс извлечения:**
   - Добавляйте console.log для понимания откуда были извлечены данные
   - Указывайте источник: структурированные данные vs fallback

4. **Тестируйте edge cases:**
   - Что происходит, если пользователь не ответил?
   - Что если ответ содержит варианты из списка?
   - Что если пользователь ответил нестандартно?
