# 🔄 Интеграция регистрации пользователей с BestBenefits

## ✅ Реализовано

### 1. **Поля в БД** (User модель)
```prisma
bestBenefitsUserId    String?   @unique  // ID пользователя в BestBenefits
bestBenefitsStatus    String?            // Статус (active, blocked)
bestBenefitsCreatedAt DateTime?          // Дата создания в BB
```

### 2. **Модуль интеграции** (`lib/best-benefits-users.ts`)
- `createBestBenefitsUser()` - создание пользователя в BB
- `changeBestBenefitsUserStatus()` - изменение статуса
- `syncUserToBestBenefits()` - синхронизация при регистрации

### 3. **Автоматическая синхронизация**
При регистрации нового пользователя (`app/api/auth/register/verify-code/route.ts`):
1. Генерируется случайный пароль
2. Пользователь создается в нашей БД
3. **Автоматически** создается в BestBenefits с теми же учетными данными
4. Пароль отправляется на email

## 🔐 Схема работы

### Учетные данные для API:
```env
BB_LOGIN="YOUR_BESTBENEFITS_EMAIL"     # Учетка организации для API
BB_PASSWORD="123"                    # Пароль организации для API
```

### Пользователь регистрируется:
```
Email: user@example.com
Пароль: [генерируется автоматически]
```

### Результат:
- ✅ Аккаунт на **нашей платформе**: `user@example.com` + пароль
- ✅ Аккаунт в **BestBenefits**: `user@example.com` + **тот же пароль**
- ✅ Доступ ко всем скидкам BestBenefits

## 🚀 Как это работает

1. **Пользователь регистрируется:**
   - Вводит email
   - Получает временный пароль на почту

2. **Автоматически создается в BestBenefits:**
   - С тем же email
   - С тем же паролем
   - ID сохраняется в `bestBenefitsUserId`

3. **Результат:**
   - Доступ к платформе профсоюза ✅
   - Доступ ко всем скидкам BestBenefits ✅
   - Одна регистрация для всего ✅
