# Инструкция по настройке входа через Яндекс ID

## Шаг 1: Создание OAuth приложения в Яндекс

1. **Перейдите на страницу создания приложения:**
   - Откройте: https://oauth.yandex.ru/client/new
   - Войдите в свой аккаунт Яндекс

2. **Шаг 1 из 4: Основная информация**
   - **Название приложения:** `MyUnion - Профсоюз работников здравоохранения`
   - **Описание:** `Платформа для управления профсоюзом работников здравоохранения РФ`
   - **Платформы:** ✅ **Веб-сервисы** (обязательно отметьте)
   - Нажмите **"Продолжить"**

3. **Шаг 2 из 4: Платформы приложений**
   - ✅ **Веб-сервисы** (уже должно быть отмечено)
   - Нажмите **"Продолжить"**

4. **Шаг 3 из 4: Настройки веб-сервиса**
   - **Redirect URI #1:** `https://myunion.pro/api/auth/callback/yandex`
   - Нажмите кнопку **"+"** справа и добавьте второй URI:
   - **Redirect URI #2 (для локальной разработки):** `http://localhost:3004/api/auth/callback/yandex`
   - **Suggest Hostname (опционально):** `myunion.pro`
   - Нажмите **"Продолжить"**

5. **Шаг 4 из 4: Доступ к данным (Права доступа)**
   В разделе **"Основные"** отметьте:
   - ✅ **Доступ к адресу электронной почты** (`login:email`)
   - ✅ **Доступ к номеру телефона** (`login:phone`)
   - ✅ **Доступ к логину, имени и фамилии, полу** (`login:info`)
   - ✅ **Доступ к портрету пользователя** (`login:avatar`)
   - ✅ **Доступ к дате рождения** (`login:birthday`) - опционально
   - Нажмите **"Создать приложение"**
   
   **ВАЖНО:** Scope должны точно совпадать с теми, что указаны в коде!

6. **Получите Client ID и Client Secret:**
   - После создания приложения вы увидите:
     - **ID приложения** (Client ID) - скопируйте его
     - **Пароль приложения** (Client Secret) - скопируйте его (показывается только один раз!)

## Шаг 2: Добавление переменных окружения

Добавьте переменные окружения в `.env.local`:
- `YANDEX_CLIENT_ID=YOUR_YANDEX_CLIENT_ID`
- `YANDEX_CLIENT_SECRET=YOUR_YANDEX_CLIENT_SECRET`

**ВАЖНО:** Добавьте эти же переменные на сервере в `.env` файл!

## Шаг 3: Настройка NextAuth

Провайдер Яндекс уже добавлен в код. После добавления переменных окружения вход через Яндекс будет работать автоматически.

## Важные моменты:

1. **Callback URI должны точно совпадать** с указанными выше
2. **Client Secret показывается только один раз** - сохраните его сразу
3. **Для локальной разработки** используйте `http://localhost:3004`
4. **Для продакшена** используйте `https://myunion.pro`

## Что будет синхронизироваться:

- ✅ Email адрес
- ✅ Номер телефона
- ✅ Имя и фамилия
- ✅ Аватар (если доступен)

## Проверка работы:

После настройки:
1. Перейдите на страницу входа: `/login`
2. Нажмите кнопку "Войти с Яндекс"
3. Авторизуйтесь через Яндекс ID
4. Проверьте, что данные синхронизировались в профиле
