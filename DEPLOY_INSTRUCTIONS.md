# 🚀 Инструкция по деплою на продакшн

## ⚠️ ВАЖНО
На продакшн сервере используется **устаревшая версия кода** без последних фиксов для:
- DaData API (адрес и ФИО)
- Справочников должностей и профессий
- Исправления зацикливания бота
- Поддержки турецких суффиксов ("улы", "кызы")
- Автофокуса в чате

---

## 📋 Шаги деплоя

### 1. SSH подключение к серверу

```bash
ssh user@myunion.pro
# Или используйте ваш SSH ключ
```

### 2. Переход в директорию проекта

```bash
cd /path/to/my-union-pro-ai
```

### 3. Остановка приложения

```bash
pm2 stop all
```

### 4. Получение последних изменений

```bash
git pull origin main
```

### 5. Установка зависимостей (если были изменения)

```bash
npm install
```

### 6. Обновление Prisma Client

```bash
npx prisma generate
```

### 7. Синхронизация схемы БД

```bash
npx prisma db push
```

**⚠️ Внимание:** Эта команда синхронизирует схему БД без создания миграций.
Убедитесь, что у вас есть бэкап БД!

### 8. Добавление справочников (НОВОЕ!)

```bash
npx tsx prisma/seed-dictionaries.ts
```

Это добавит:
- 142 должности
- 95 профессий

### 9. Пересборка приложения

```bash
npm run build
```

### 10. Перезапуск приложения

```bash
pm2 restart all
pm2 save
```

### 11. Проверка логов

```bash
pm2 logs
```

Убедитесь, что нет ошибок при запуске.

## 🔧 Troubleshooting

### Ошибка: "Module not found"

```bash
npm install
npx prisma generate
npm run build
pm2 restart all
```

### Ошибка: "Database schema is out of sync"

```bash
npx prisma db push --force-reset
npx tsx prisma/seed-dictionaries.ts
```

### Ошибка: "DaData API 401/403"

Проверьте переменные окружения на продакшн сервере:

```bash
cat .env | grep DADATA
```

Должны быть:
```
DADATA_API_KEY=your_api_key
DADATA_SECRET_KEY=your_secret_key
```

### Ошибка: "Port already in use"

```bash
pm2 delete all
pm2 start npm --name "myunion" -- start
pm2 save
```

## 📊 Что изменилось в последнем обновлении

### 🆕 Новые функции:
1. **Справочники должностей и профессий** (142 + 95 записей)
2. **Автокомплит** для полей "Должность" и "Профессия" в профиле
3. **Улучшенная валидация DaData** для адресов и ФИО
4. **Поддержка турецких суффиксов** ("улы", "кызы") в отчествах
5. **Автофокус в чате** - курсор не слетает после отправки сообщения

### 🐛 Исправленные баги:
1. Бот не зацикливается на подтверждении полей
2. Бот не спрашивает дважды про одно и то же
3. Адрес корректно валидируется через DaData Suggestions API
4. Город извлекается полностью: "Набережные Челны"
5. Приветствие не дублируется при обновлении страницы
6. Чат автоматически скроллится к новым сообщениям
