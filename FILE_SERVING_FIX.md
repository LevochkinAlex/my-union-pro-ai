# Исправление отображения изображений на продакшене

## Проблема

Изображения в чате не отображались на продакшене, показывалась ошибка "путь нарушен".

### Причины

1. **Serverless окружение**: На платформах типа Vercel/Netlify файловая система эфемерна
2. **Статические файлы**: Next.js не обслуживает файлы из `public/uploads/` автоматически
3. **Прямые пути**: Изображения использовали прямые пути типа `/uploads/chat/filename.jpg`

## Решение

### 1. API Route для обслуживания файлов

Создан новый API endpoint: `/app/api/uploads/chat/[filename]/route.ts`

**Функции:**
- Безопасное чтение файлов из `public/uploads/chat/`
- Защита от path traversal атак
- Правильные MIME types для всех форматов
- Кэширование (1 год) для оптимизации

**Поддерживаемые форматы:**
- Изображения: JPG, PNG, GIF, WebP, HEIC, HEIF, SVG
- Документы: PDF, DOC, DOCX, TXT
- Видео: MP4, WebM, MOV

### 2. Helper функция `getFileUrl()`

Добавлена в `app/dashboard/chat/page.tsx`:

```typescript
const getFileUrl = (filePath: string) => {
  if (!filePath) return "";
  if (filePath.startsWith("http://") || filePath.startsWith("https://")) {
    return filePath; // Уже полный URL
  }
  const filename = filePath.split("/").pop();
  return `/api/uploads/chat/${filename}`; // Преобразуем в API endpoint
};
```

### 3. Обновлены все места отображения

- Превью изображений в сообщениях
- Открытие в новом окне
- Скачивание файлов
- Редактирование сообщений с вложениями

## Как это работает

**До:**
```
/uploads/chat/1234567890-abc.jpg  ❌ Не работает на проде
```

**После:**
```
/api/uploads/chat/1234567890-abc.jpg  ✅ Работает везде
```

API route читает файл из файловой системы и возвращает его с правильными заголовками.

## Преимущества

1. ✅ Работает на любом хостинге (Vercel, Netlify, и т.д.)
2. ✅ Защита от несанкционированного доступа
3. ✅ Оптимизировано кэшированием
4. ✅ Поддержка всех форматов файлов
5. ✅ Работает одинаково на dev и prod

## Миграция на облачное хранилище (опционально)

Если в будущем понадобится хранить файлы в облаке (S3, Cloudinary, Vercel Blob), достаточно:

1. Обновить функцию `getFileUrl()` для генерации правильных URL
2. Обновить API routes для загрузки в облако
3. Никаких изменений в UI не требуется!
