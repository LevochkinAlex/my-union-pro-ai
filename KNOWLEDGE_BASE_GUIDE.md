# 📚 Руководство по Knowledge Base (Базе Знаний)

## 🎯 Что это такое?

Knowledge Base (База Знаний) — это система, которая позволяет AI-боту использовать загруженные документы для более точных и информированных ответов.

## 🏗️ Архитектура системы

### **1. Компоненты базы данных:**

```
KnowledgeBase (База знаний)
├── KnowledgeDocument (Документы)
│   └── KnowledgeChunk (Фрагменты текста с embeddings)
└── KnowledgeSource (Внешние источники - API, RSS и др.)
```

### **2. Поддерживаемые форматы файлов:**

✅ **PDF** - документы, инструкции, регламенты  
✅ **DOCX** - Word документы  
✅ **XLSX** - Excel таблицы  
✅ **CSV** - данные в табличном формате  
✅ **TXT** - текстовые файлы  

### **3. Процесс обработки документа:**

```
1. Загрузка файла через админку
   ↓
2. Извлечение текста (lib/knowledge/extract.ts)
   ↓
3. Разбивка на chunks (~1000 токенов) (lib/knowledge/chunker.ts)
   ↓
4. Генерация embeddings (векторные представления) (lib/knowledge/embeddings.ts)
   ↓
5. Сохранение в БД (KnowledgeChunk)
   ↓
6. Готово к использованию ботом!
```

## 📖 Как это работает сейчас

### ✅ **Что работает:**

1. **Загрузка документов** - Через `/admin/ai-chat/knowledge-bases/[id]`
2. **Извлечение текста** - Из всех поддерживаемых форматов
3. **Разбивка на chunks** - Текст делится на фрагменты
4. **Связь с ботом** - Бот может быть привязан к нескольким базам знаний

### ⚠️ **Что упрощено (требует доработки):**

1. **Семантический поиск отключён**
   - Сейчас: бот получает ВСЕ chunks из базы (неоптимально)
   - Нужно: поиск по embeddings с cosine similarity

2. **Embeddings не генерируются**
   - Функция `generateEmbedding()` есть, но не используется
   - Причина: экономия токенов и времени обработки

## 🚀 Как использовать

### **1. Создание базы знаний:**

```
Админка → AI Chat → Базы знаний → Создать новую базу
```

- Название: например "Устав профсоюза"
- Описание: краткое описание содержимого
- Статус: Активна

### **2. Загрузка документов:**

```
Открыть базу знаний → Загрузить документы → Выбрать файлы
```

Документы автоматически:
- Сохраняются в `/uploads/knowledge/`
- Обрабатываются в фоне (через BullMQ очередь)
- Разбиваются на chunks
- Становятся доступны боту

### **3. Привязка к боту:**

```
Админка → AI Chat → Боты → Редактировать бота
→ Выбрать базы знаний
```

Бот автоматически будет использовать знания из выбранных баз при ответах.

## 💡 Примеры использования

### **Пример 1: Устав профсоюза**

```
База знаний: "Устав МООП РЗ"
Документы:
  - Устав.pdf
  - Положение о членстве.docx
  - Порядок приема.pdf
```

Бот сможет отвечать на вопросы:
- "Какие требования для вступления?"
- "Какие взносы нужно платить?"
- "Какие права у членов?"

### **Пример 2: Шаблоны заявлений**

```
База знаний: "Образцы документов"
Документы:
  - Заявление_о_вступлении_образец.docx
  - Заявление_на_взносы_образец.docx
```

Бот будет использовать эти шаблоны как reference при генерации новых заявлений.

## 🔧 Техническая информация

### **Основные файлы:**

- `lib/knowledge/extract.ts` - извлечение текста из файлов
- `lib/knowledge/chunker.ts` - разбивка на фрагменты
- `lib/knowledge/embeddings.ts` - генерация векторных представлений
- `lib/knowledge/processor.ts` - координатор обработки
- `lib/queues/knowledgeQueue.ts` - фоновая очередь обработки

### **API endpoints:**

- `POST /api/admin/knowledge-bases` - создать базу
- `GET /api/admin/knowledge-bases` - список баз
- `GET /api/admin/knowledge-bases/[id]` - детали базы
- `POST /api/admin/knowledge-bases/[id]/documents` - загрузить документ
- `DELETE /api/admin/knowledge-bases/[id]/documents/[docId]` - удалить документ

### **Статусы обработки:**

- `UPLOADED` - файл загружен
- `QUEUED` - в очереди на обработку
- `PROCESSING` - обрабатывается
- `COMPLETED` - обработан успешно
- `FAILED` - ошибка обработки

## 📊 Текущие ограничения

1. **Максимальный размер файла:** ~10MB (настраивается в multer)
2. **Формат embeddings:** OpenAI text-embedding-3-small (1536 dimensions)
3. **Chunk size:** ~1000 токенов с overlap 200 токенов
4. **Максимум chunks в контексте:** 10 (можно увеличить)
