# ⚠️ СРОЧНО: Настройте DaData API

> **Без этого организации НЕ будут проверяться по реестру Минюста РФ!**

---

## 🎯 Проблема

В сессии чата AI написал:
> "Я нашел вашу организацию: БСМП Гор больница Челны"

**Вместо правильного:**
> "Я нашел вашу организацию: ГАУЗ «Больница скорой медицинской помощи города Набережные Челны» (в реестре Минюста РФ)"

**Причина:** Не настроен API ключ `DADATA_API_KEY`

---

## ✅ Решение (3 минуты)

### 1. Получите ключ на dadata.ru

- Регистрация: [https://dadata.ru/](https://dadata.ru/)
- Бесплатно: 10,000 запросов/день
- Скопируйте API токен

### 2. Добавьте в `.env.local`

Откройте файл `.env.local` и добавьте строку:

```bash
DADATA_API_KEY="ваш_токен_здесь"
```

### 3. Перезапустите сервер

```bash
npm run dev
```

### 4. Проверьте в логах

Должно появиться при упоминании организации:

```
[organization-search] Searching organization in DaData/Minjust: ...
[organization-search] Organization found in DaData/Minjust: ГАУЗ «Больница...»
```
