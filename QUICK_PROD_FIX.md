# 🚀 Быстрое исправление на PROD

## Проблема
Сообщения не удаляются, потому что миграция не применена на PROD базе данных.

## Решение (5 минут)

### Вариант 1: Через SSH на VDS

```bash
# 1. Подключитесь к серверу
ssh root@194.87.49.210
# Пароль: sAt,8?Bh+Ny_BW

# 2. Перейдите в директорию проекта
cd /opt/my-union-pro

# 3. Обновите код из git
git pull origin main

# 4. Примените миграцию
pnpm prisma migrate deploy

# 5. Перезапустите приложение
pm2 restart my-union-pro

# 6. Проверьте логи
pm2 logs my-union-pro --lines 50
```

### Вариант 2: Через SQL напрямую в базу данных

Если у вас есть доступ к PROD базе данных (Supabase/Railway/etc):

1. Откройте SQL редактор
2. Скопируйте SQL из файла `MIGRATION_SQL.sql`
3. Выполните его
4. Перезапустите приложение на сервере

### Вариант 3: Одной командой с локальной машины

```bash
# Выполните с вашего компьютера
ssh root@194.87.49.210 'cd /opt/my-union-pro && git pull origin main && pnpm prisma migrate deploy && pm2 restart my-union-pro'
```

Пароль: `sAt,8?Bh+Ny_BW`

## ✅ Проверка после исправления

1. Откройте https://myunion.pro/dashboard/chat
2. Очистите кэш браузера (Cmd+Shift+R)
3. Попробуйте удалить сообщение

## 📝 Что делает миграция

Добавляет в таблицу `ChatMessage` поля:
- `deletedAt` - для удаления
- `editedAt` - для редактирования
- `replyToId` - для ответов
- `forwardedFromId` - для пересылки

Без этих полей функции не работают.
