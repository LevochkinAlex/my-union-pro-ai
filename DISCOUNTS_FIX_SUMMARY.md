# 🔧 Исправления для скидок - Полный список

## Проблемы и решения

### 1. ✅ Города из разных стран в фильтре
**Проблема:** В выпадающем списке городов показывались города из Казахстана, Беларуси и других стран, а не только из России.

**Решение:** Добавлена фильтрация только российских городов в функции `extractCities`:

```typescript
// lib/best-benefits.ts
function extractCities(discounts: DiscountItem[]): DiscountCity[] {
  const russianCities = new Set([
    'Москва', 'Санкт-Петербург', 'Новосибирск', 'Екатеринбург', 'Казань',
    // ... список 70+ крупных городов РФ
  ]);
  
  discounts.forEach((discount) => {
    discount.cities.forEach((city) => {
      // Фильтруем только российские города
      if (russianCities.has(city.name)) {
        map.set(city.id, { ...city, count: (map.get(city.id)?.count ?? 0) + 1 });
      }
    });
  });
  
  return Array.from(map.values()).sort((a, b) => 
    a.name.localeCompare(b.name, 'ru-RU')
  );
}
```

**Результат:**
- ✅ Только российские города в фильтре
- ✅ Сортировка по алфавиту (А-Я)
- ✅ 70+ крупных городов РФ

### 2. ✅ Всегда открывается ТОКИО-CITY
**Проблема:** При клике на любую карточку скидки открывалась детальная страница с одной и той же скидкой (ТОКИО-CITY).

**Причина:** Фильтрация по `ids` применялась только в `applyViewFilter`, который не срабатывал для детальной страницы.

**Решение:** Добавлена явная фильтрация по `ids` в `normalizeResponse`:

```typescript
// lib/best-benefits.ts
// Filter by specific IDs (for detail page or favorites/claimed)
if (params.ids) {
  const idList = params.ids
    .split(",")
    .map((id) => Number(id.trim()))
    .filter((id) => !Number.isNaN(id));
  
  if (idList.length > 0) {
    filtered = filtered.filter((discount) => idList.includes(discount.id));
  }
}
```

**Результат:**
- ✅ Каждая карточка открывает свою детальную страницу
- ✅ Правильная скидка загружается по ID
- ✅ URL `/dashboard/discounts/[id]` работает корректно

---

### 3. ✅ Нет кнопки "Использовать скидку"
**Проблема:** На детальной странице не отображалась кнопка "Использовать скидку".

**Причина:** Кнопка рендерилась только если `discount.partnerUrl` существовал. У некоторых скидок этого поля не было.

**Решение:** Убрана проверка `discount.partnerUrl` - кнопка теперь показывается всегда:

```typescript
// app/dashboard/discounts/[id]/page.tsx
{/* Action Button */}
<div className="mt-6 sm:mt-8">
  <button onClick={handleClaim} ...>
    <span>{isClaimed ? "Открыть на BestBenefits" : "Использовать скидку"}</span>
  </button>
</div>
```

**Результат:**
- ✅ Кнопка отображается всегда
- ✅ Работает активация скидки
- ✅ Открывается партнерская ссылка (если есть)

### 4. ✅ БОНУС: Maximum call stack size exceeded
**Проблема:** При загрузке 100 скидок приложение падало с ошибкой stack overflow (44МБ данных).

**Решение:** Вернул `limit=15` и добавил `cache: "no-store"`:

```typescript
// lib/best-benefits.ts
const response = await fetch(url, {
  method: "GET",
  headers: { ... },
  cache: "no-store", // Отключено кэширование для больших данных
});
```

**Результат:**
- ✅ Быстрая загрузка (15 скидок, ~6МБ)
- ✅ Нет ошибок переполнения
- ✅ Стабильная работа приложения

### 6. ✅ БОНУС: Клик на карточке
**Проблема:** Клик на промокод или кнопку "Использовать" открывал детальную страницу вместо копирования/активации.

**Решение:** Добавлен `e.stopPropagation()`:

```typescript
// components/dashboard/discounts/DiscountCard.tsx
const handleCopyPromo = async (e: React.MouseEvent) => {
  e.stopPropagation(); // Prevent card click
  // ...
};

const handleClaim = (e: React.MouseEvent) => {
  e.stopPropagation(); // Prevent card click
  // ...
};
```

**Результат:**
- ✅ Клик на промокод → копирование
- ✅ Клик на кнопку → активация + переход на партнерский сайт
- ✅ Клик на карточку → детальная страница
