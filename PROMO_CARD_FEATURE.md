# ✅ Генератор карточек с промокодами

## 🎨 Описание

Функция автоматической генерации красивых карточек с промокодами для скачивания. Карточки включают QR-код, промокод, ФИО пользователя и информацию о скидке.

## 📦 Что реализовано:

### 1. Библиотека для генерации (`lib/promo-card-generator.ts`)

```typescript
// Генерирует карточку с промокодом
async function generatePromoCard(data: PromoCardData): Promise<string>

// Скачивает карточку
function downloadPromoCard(dataUrl: string, fileName: string)

// Генерирует и скачивает (все в одном)
async function generateAndDownloadPromoCard(data: PromoCardData)
```

### 2. Дизайн карточки

**Размер:** 1200x630px (оптимально для социальных сетей)

**Элементы:**
- 🎨 Градиентный фон (фиолетовый → темно-фиолетовый)
- 📄 Белая карточка с тенью и скругленными углами
- 🏷️ Логотип "MyUnion" в левом верхнем углу
- 📝 Название скидки
- 📱 QR-код (200x200px, справа вверху)
- 🎫 Промокод крупным шрифтом в рамке
- 👤 ФИО пользователя
- ⏰ Срок действия промокода

**Пример карточки:**

## 🔧 Технические детали

### Зависимости:

```json
{
  "qrcode": "^1.5.4",
  "@types/qrcode": "^1.5.6"
}
```

### API функции:

```typescript
interface PromoCardData {
  promoCode: string;       // Промокод (обязательно)
  userName: string;        // ФИО пользователя (обязательно)
  discountName: string;    // Название скидки (обязательно)
  discountImage?: string;  // URL изображения скидки (опционально)
  validUntil?: string;     // Дата истечения (опционально)
}
```

### Использование:

```typescript
import { generateAndDownloadPromoCard } from "@/lib/promo-card-generator";

// Генерация и скачивание
await generateAndDownloadPromoCard({
  promoCode: "BESTBENEFITS",
  userName: "Виталий Еременко",
  discountName: "Сеть ресторанов Domino's Pizza",
  validUntil: "2027-12-31",
});
```

## 🐛 Известные ограничения

1. **Canvas API:**  
   Работает только в браузере (не на сервере)

2. **Шрифты:**  
   Используются системные шрифты  
   Для кастомных шрифтов нужна предзагрузка

3. **Размер файла:**  
   ~100-300KB в зависимости от содержимого

4. **Поддержка браузеров:**  
   Требуется современный браузер с Canvas API
