# 📱 Настройка SendPulse для WhatsApp и SMS

## 🎯 Что реализовано

**Интеллектуальная система доставки PIN-кодов** с автоматическим fallback:

1. **Приоритет 1:** Telegram (если привязан) 📱
2. **Приоритет 2:** WhatsApp через SendPulse 💬
3. **Приоритет 3:** SMS через SendPulse 📨

Система автоматически пытается все каналы по порядку, пока код не будет доставлен!

---

## 📋 Шаг 1: Регистрация в SendPulse

### 1.1. Создайте аккаунт

1. Перейдите: https://sendpulse.com/ru/
2. Зарегистрируйтесь (Email + пароль)
3. Подтвердите email

### 1.2. Получите API ключи

1. В личном кабинете: **Settings → API**
2. Или прямая ссылка: https://login.sendpulse.com/settings/#api
3. Скопируйте:
   - **ID** (client_id): `YOUR_SENDPULSE_USER_ID`
   - **Secret** (client_secret): `YOUR_SENDPULSE_SECRET`

### 1.3. Добавьте в `.env.local`:

```env
# SendPulse для WhatsApp и SMS
SENDPULSE_USER_ID=YOUR_SENDPULSE_USER_ID
SENDPULSE_SECRET=YOUR_SENDPULSE_SECRET
```

---

## 📋 Шаг 2: Настройка WhatsApp Business

### 2.1. Подключение WhatsApp

1. В SendPulse: **Мессенджеры → WhatsApp**
2. Выберите: **WhatsApp Business API**
3. Привяжите номер телефона вашей компании
4. Следуйте инструкциям для верификации через Facebook Business

**Важно:**
- Верификация может занять **1-2 рабочих дня**
- Нужен **Facebook Business Manager аккаунт**
- Номер должен быть **не привязан к обычному WhatsApp**

### 2.2. Лимиты WhatsApp

**Free план:**
- Первые **1000 сообщений/месяц** - бесплатно
- Далее платно (цена зависит от страны получателя)

**Ограничения:**
- Можно отправлять только **шаблонные сообщения** (template messages)
- Или сообщения в течение **24 часов** после инициации диалога пользователем

---

## 📋 Шаг 3: Настройка SMS

### 3.1. Активация SMS

1. В SendPulse: **SMS**
2. Выберите страну: **Россия**
3. Пополните баланс (минимум 500 руб)

### 3.2. Имя отправителя

По умолчанию: `MyUnion` (до 11 символов, только латиница)

Для изменения отредактируйте в `lib/sendpulse.ts`:

```typescript
sender: "MyUnion", // Измените на свое имя
```

### 3.3. Стоимость SMS

**Россия:**
- ~3-5 руб за SMS
- Зависит от оператора (МТС, Билайн, Мегафон, Теле2)

## 🎯 Как работает система доставки

### Процесс отправки PIN-кода:

1. **Пользователь запрашивает код**
   ```
   POST /api/auth/sms/send-pin
   { "phone": "+79991234567" }
   ```

2. **Система проверяет каналы доставки:**

   **Шаг 1:** Проверяет, есть ли привязанный Telegram
   - ✅ Если есть → отправляет в Telegram
   - ❌ Если нет → переходит к шагу 2

   **Шаг 2:** Пытается отправить через WhatsApp
   - ✅ Если успешно → код доставлен
   - ❌ Если ошибка → переходит к шагу 3

   **Шаг 3:** Отправляет SMS (последний fallback)
   - ✅ Если успешно → код доставлен
   - ❌ Если ошибка → возвращает ошибку пользователю

3. **Ответ API:**
   ```json
   {
     "success": true,
     "deliveryMethod": "whatsapp",
     "message": "Код подтверждения отправлен в WhatsApp 💬"
   }
   ```

### Логирование:

Все попытки доставки логируются с префиксом `[2FA Auth]`:

```
[2FA Auth] Попытка отправки через Telegram на chat_id: 123456789
[2FA Auth] ❌ Telegram не сработал: Chat ID не найден
[2FA Auth] Попытка отправки через WhatsApp на номер: +79991234567
[2FA Auth] ✅ PIN-код успешно отправлен через WhatsApp
```

  -d '{

    "body": "Тестовое сообщение"

2. Введите номер телефона

4. Проверьте:
   - Telegram (если привязан)
   - WhatsApp
   - SMS
5. Введите код на сайте
6. Войдите в систему ✅

## 🔧 Troubleshooting

### Ошибка: "Не удалось получить токен SendPulse"

**Причина:** Неверные API ключи

**Решение:**
1. Проверьте `SENDPULSE_USER_ID` и `SENDPULSE_SECRET` в `.env.local`
2. Убедитесь, что ключи скопированы полностью
3. Перезапустите сервер

### Ошибка WhatsApp: "WhatsApp not configured"

**Причина:** WhatsApp Business не настроен в SendPulse

**Решение:**
1. Завершите настройку WhatsApp Business в SendPulse
2. Дождитесь верификации от Facebook (1-2 дня)
3. Пока WhatsApp не готов, система автоматически использует SMS

### Ошибка SMS: "Insufficient balance"

**Причина:** Недостаточно средств на балансе SendPulse

**Решение:**
1. Пополните баланс в SendPulse (минимум 500 руб)
2. SMS будет работать автоматически

### PIN-код не приходит ни по одному каналу

**Проверьте:**
1. Логи сервера: `[2FA Auth]` для деталей ошибок
2. Баланс SendPulse (для SMS)
3. Статус WhatsApp Business (должен быть Active)
4. Правильность номера телефона (должен быть в формате +7XXXXXXXXXX)

### В dev режиме PIN-код не отображается в консоли

**Решение:**
1. Откройте DevTools (F12)
2. Вкладка **Console**
3. Ищите строку: `🔑 PIN-код (только для разработки): XXXX`
