#### `lib/chat-utils.ts`
- `getOrCreatePrivateChat()` - создание или поиск личного чата между двумя пользователями

- `getPPOHead()` - проверка и получение данных Председателя

   - Проверить, что отправляется уведомление

2. **Создание чата при отклонении заявки**
   - Проверить, что создается чат между Председателем и членом

   - Проверить создание документа по шаблону

6. **Обработка обращений**
   - Проверить создание чата при создании обращения
   - Проверить отклонение обращения с причиной

## Известные проблемы и улучшения

### Требует внимания:

1. **Обработка ошибок в уведомлениях**
   - В некоторых местах ошибки отправки уведомлений логируются, но не блокируют выполнение
   - Это правильное поведение, но можно добавить retry механизм

2. **Валидация данных**
   - Добавить более строгую валидацию входных данных в API endpoints
   - Использовать библиотеку валидации (например, Zod)

3. **Производительность**
   - Рассмотреть добавление кэширования для часто запрашиваемых данных
   - Оптимизировать запросы с использованием `include` вместо отдельных запросов

4. **Безопасность**
   - Добавить rate limiting для API endpoints
   - Улучшить проверку прав доступа
