# 🔍 Режим отладки чат-бота

Инструмент для анализа работы AI бота и отладки экстракции данных.

## Доступ

**URL:** http://localhost:3004/admin/chat-debug

**Доступ:** Только для `SUPER_ADMIN`

---

## Возможности

### 1️⃣ Просмотр всех диалогов

- ✅ Список последних 50 сессий заявлений
- ✅ Фильтр по пользователям
- ✅ Количество сообщений в каждом диалоге
- ✅ Дата создания

### 2️⃣ Детальный анализ диалога

**Информация о сессии:**
- ID сессии
- Тип (STATEMENT/APPEAL)
- Email пользователя
- Количество сообщений

**История диалога:**
- 👤 Сообщения пользователя (синий фон)
- 🤖 Ответы бота (серый фон)
- Время каждого сообщения
- Номер сообщения в диалоге

### 3️⃣ Экстракция данных профиля

**Кнопка "🔬 Извлечь данные профиля"** запускает:

1. Анализ всей истории сообщений
2. Извлечение структурированных данных из итога бота
3. Fallback-поиск ФИО и даты в подтверждениях
4. Валидацию всех полей

**Показывает:**
- ✅ Успешно извлечённые поля
- ❌ Пропущенные или отклонённые поля
- Причины отклонения (в консоли браузера)

## Как использовать

### Сценарий 1: Проверка работы бота

1. Открой http://localhost:3004/admin/chat-debug
2. Выбери сессию из списка
3. Просмотри историю диалога
4. Найди где бот "затупил":
   - Неправильно задал вопрос
   - Не распознал ответ
   - Не подтвердил данные
   - Показал пустые поля в итоге

### Сценарий 2: Проверка экстракции данных

1. Выбери сессию где пользователь завершил диалог
2. Нажми "🔬 Извлечь данные профиля"
3. Проверь какие данные извлеклись:
   - ✅ **firstName, lastName, middleName**: Должны быть из подтверждения "Ваше ФИО: ... Верно?"
   - ✅ **dateOfBirth**: Должна быть из "Ваша дата рождения: ДД.ММ.ГГГГ. Верно?"
   - ✅ **phone, address, jobTitle...**: Должны быть из итогового сообщения
4. Если поле пустое:
   - Открой консоль браузера (F12)
   - Найди логи `[profile-extraction]`
   - Проверь почему данное поле было отклонено

### Сценарий 3: Отладка пустых полей в итоге

**Проблема:** Бот показал "**ФИО**: " (пусто) в итоге.

**Решение:**

1. Открой сессию в отладчике
2. Найди подтверждение ФИО: "Ваше ФИО: Усманов Ренат Рушан улы. Верно?"
3. Если есть → проверь регулярное выражение в `lib/profile-extraction.ts` (функция fallback)
4. Если нет → проблема в системном промпте бота (`app/api/chat/route.ts`)

**Как исправить промпт:**
- Добавь четкие инструкции искать данные в своих СОБСТВЕННЫХ подтверждениях
- Запрети оставлять поля пустыми
- Покажи КОНКРЕТНЫЙ пример правильного итога

## Частые проблемы

### ❌ ФИО не извлекается

**Причины:**
1. Бот не подтвердил ФИО фразой "Ваше ФИО: ... Верно?"
2. Регулярное выражение не распознаёт формат
3. Данные в итоговом сообщении пустые

**Решение:** Исправь системный промпт бота

---

### ❌ Дата рождения показывает `Invalid Date`

**Причина:** Ошибка в коде деструктуризации:
```typescript
const [, day, month, year] = dobMatch[1].split('.').map(Number); // ❌ Запятая в начале!
```

**Решение:**
```typescript
const [day, month, year] = dobMatch[1].split('.').map(Number); // ✅ Без запятой
```

---

### ❌ Адрес извлекается как "Чулман 11, Челны" вместо полного

**Причина:** Бот не использует валидированный адрес от DaData в итоге.

**Решение:** Научи бота в промпте использовать адрес из своего подтверждения:
```
"Система проверила ваш адрес: **Респ Татарстан, г Набережные Челны...**"
```

## API Endpoints (для разработки)

### GET /api/admin/chat-sessions
Список последних 50 сессий

**Response:**
```json
{
  "sessions": [
    {
      "id": "...",
      "type": "STATEMENT",
      "createdAt": "2024-11-25...",
      "user": { "email": "..." },
      "messages": [...]
    }
  ]
}
```

### GET /api/admin/chat-sessions/[id]
Детали конкретной сессии со всеми сообщениями

### POST /api/admin/extract-profile
Экстракция данных профиля из сессии

**Body:**
```json
{ "sessionId": "..." }
```

**Response:**
```json
{
  "profileData": {
    "firstName": "Ренат",
    "lastName": "Усманов",
    "dateOfBirth": "16.01.1981",
    ...
  },
  "messagesCount": 37
}
```
