# 🧪 Проверка функционала скачивания скидок

## ✅ Текущая реализация

### Места, где есть кнопка "Скачать":

1. **`/dashboard/discounts/my`** - страница "Мои скидки"
   - ✅ Использует `handleWalletDownload` из `wallet-utils.ts`
   - ✅ Генерирует промокарту через `generatePromoCard`
   - ✅ Передает данные в `handleWalletDownload`

2. **`/dashboard/discounts/[id]`** - страница деталей скидки
   - ✅ Использует `handleWalletDownload` из `wallet-utils.ts`
   - ✅ Генерирует промокарту через `generatePromoCard`
   - ✅ Передает данные в `handleWalletDownload`

## 📱 Логика по платформам

### Desktop (Windows, macOS, Linux)
- ✅ Открывает PDF в новой вкладке
- ✅ Использует jsPDF для конвертации PNG → PDF
- ✅ Fallback: открывает изображение в новой вкладке

### iOS (iPhone, iPad)
- ✅ Пытается получить .pkpass файл через `/api/wallet/apple-pass`
- ⚠️ Если API не настроен (501) → скачивает PNG
- ⚠️ Если ошибка → скачивает PNG
- ⚠️ Примечание: Для полноценной работы нужны Apple сертификаты

### Android
- ✅ Пытается получить Google Pay pass через `/api/wallet/google-pass`
- ✅ Если успешно → открывает `https://pay.google.com/gp/v/save/{jwt}`
- ⚠️ Если API не настроен (501) → скачивает PNG
- ⚠️ Если ошибка → скачивает PNG

## ⚠️ Известные ограничения

1. **Apple Wallet:** Требует сертификаты Apple для генерации .pkpass файлов
2. **Google Pay:** Требует правильной настройки API и Issuer ID
3. **Fallback:** Если API не работает, всегда скачивается PNG изображение

## 🔧 Если что-то не работает

### Android не открывает Google Wallet
- Проверьте логи сервера на наличие ошибок
- Проверьте, что `GOOGLE_PAY_ISSUER_ID` в `.env.local`
- Проверьте, что Google Wallet API включен
- Проверьте консоль браузера (F12) на наличие ошибок

### Desktop не открывает PDF
- Проверьте, что jsPDF установлен
- Проверьте консоль браузера на наличие ошибок
- Fallback должен открыть изображение в новой вкладке

### iOS скачивает PNG вместо .pkpass
- Это нормально, так как Apple Wallet API еще не настроен
- Для настройки нужны сертификаты Apple Developer
