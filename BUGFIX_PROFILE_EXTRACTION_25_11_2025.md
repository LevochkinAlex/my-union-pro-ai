# 🐛 КРИТИЧЕСКИЙ БАГФИКС: Множественная перезапись полей профиля

**Дата:** 25 ноября 2025  
**Файл:** `lib/profile-extraction.ts`  
**Приоритет:** 🚨 КРИТИЧЕСКИЙ

---

## 📋 Описание проблемы

### Симптомы:
В профиле пользователя обнаружены **склеенные данные**:

```
preferredDiscountCity: "ага\nхирургия\nага\nАспирантура\nага\nда"
spouseInfo: "да двое"  (это ответ на вопрос о ДЕТЯХ!)
```

### Причина:
В функции `extractProfileDataFromMessages` в цикле обработки сообщений происходила **множественная перезапись** полей профиля БЕЗ проверки на существование значения.

```typescript
// ❌ БАГ: Перезаписывается на каждой итерации!
for (let i = 0; i < messages.length - 1; i++) {
  if (botQuestion.includes('супруг')) {
    profileData.spouseInfo = userAnswer;  // ПЕРЕЗАПИСЬ!
  }
}
```

При обработке 50+ сообщений, если в вопросе бота было ключевое слово (например "супруг"), то на **каждой итерации** значение перезаписывалось последним ответом пользователя, даже если ответ был на ДРУГОЙ вопрос!

---

## 🔧 Исправление

Добавлена проверка существования значения **ПЕРЕД** присваиванием для всех полей:

### До:
```typescript
if (botQuestion.includes('супруг') && ...) {
  profileData.spouseInfo = userAnswer;  // ❌ Всегда перезаписывает!
}
```

### После:
```typescript
if (!profileData.spouseInfo && botQuestion.includes('супруг') && ...) {
  profileData.spouseInfo = userAnswer;  // ✅ Записывает только если пусто!
}
```

---

## 📝 Исправленные поля

Добавлена проверка `!profileData.field` для следующих полей:

1. ✅ **`employmentStatus`** (Занятость)
2. ✅ **`maritalStatus`** (Семейное положение)
3. ✅ **`spouseInfo`** (Информация о супруге/супруге)
4. ✅ **`hasChildren`** (Есть ли дети) - проверка `=== undefined` т.к. это boolean
5. ✅ **`hobbies`** (Хобби)
6. ✅ **`aboutMe`** (О себе)
7. ✅ **`additionalInfo`** (Дополнительная информация)

## ⚠️ Важные замечания

### Почему проблема не возникала с другими полями?

Поля типа `jobTitle`, `profession`, `address` и т.д. **УЖЕ ИМЕЛИ** проверку `!profileData.field`:

```typescript
if (userAnswer.length >= 2 && userAnswer.length <= 100) {
  if (!profileData.jobTitle) {  // ✅ Проверка была!
    profileData.jobTitle = userAnswer;
  }
}
```

Но поля `employmentStatus`, `maritalStatus`, `spouseInfo` и т.д. этой проверки **НЕ ИМЕЛИ** → происходила перезапись!
