# 🛠️ Настройка локальной разработки

## Подключение к продакшн базе данных через SSH туннель

### Быстрый старт

1. **Откройте первый терминал** и запустите SSH туннель:
   ```bash
   ./scripts/db-tunnel.sh
   ```
   
   Или вручную:
   ```bash
   ssh -i ~/.ssh/myunion_vds -L 5432:localhost:5432 -N root@194.87.49.210
   ```

2. **Откройте второй терминал** и запустите dev-сервер:
   ```bash
   npm run dev
   ```

3. **Откройте браузер**: http://localhost:3004

### ⚠️ Важно

- **Не закрывайте терминал с туннелем** во время разработки
- Туннель должен быть запущен **до** старта `npm run dev`
- Если получаете ошибки БД — проверьте, что туннель активен

### Остановка

1. В терминале с dev-сервером: `Ctrl+C`
2. В терминале с туннелем: `Ctrl+C`

### Конфигурация

`.env.local` настроен на работу через туннель:
```env
DATABASE_URL="postgresql://myunion_user:myunion_secure_password_2024@localhost:5432/myunion_db"
```

### Восстановление прямого подключения

Если нужно вернуть прямое подключение к продакшн БД:
```bash
# Восстановить из бэкапа
cp .env.local.backup-* .env.local
```

Или изменить вручную `localhost` на `194.87.49.210` в `DATABASE_URL`.

### Проверка туннеля

Проверить, что туннель работает:
```bash
# В другом терминале
psql "postgresql://myunion_user:myunion_secure_password_2024@localhost:5432/myunion_db" -c "SELECT version();"
```

Если команда работает — туннель активен! ✅
