## 📊 Поля которые СОБИРАЮТСЯ

### 1️⃣ ОБЯЗАТЕЛЬНЫЕ (для заявления)

Собираются в ПЕРВУЮ очередь, ПЕРЕД генерацией документов:

1. **Регион** (`region`) - Регион России
2. **Организация** (`organizationId`, `organization.name`) - Место работы (с поиском в ЕГРЮЛ/Минюст)
3. **ФИО** (`firstName`, `lastName`, `middleName`) - Фамилия, Имя, Отчество
4. **Дата рождения** (`dateOfBirth`) - DD.MM.YYYY
5. **Адрес** (`address`) - Полный адрес проживания (с валидацией DaData)
6. **Телефон** (`phone`) - Номер телефона
7. **Должность** (`jobTitle`) - Занимаемая должность
8. **Профессия** (`profession`) - Основная профессия
9. **Образование** (`education`) - Уровень образования

**После сбора:** Подтверждение всех данных в структурированном формате

---

### 2️⃣ ДОПОЛНИТЕЛЬНЫЕ (после генерации)

Собираются ПОСЛЕ генерации заявления:

1. **Занятость** (`employmentStatus`) - Работа / Учеба / Пенсия
2. **Семейное положение** (`maritalStatus`) - Не женат / Женат / В разводе / Вдовец / В гражданском браке
3. **Супруг/супруга** (`spouseInfo`) - Информация о супруге (только если в браке)
4. **Дети** (`hasChildren`, `childrenInfo`, `childrenBirthDates`):
   - Есть ли дети (Boolean)
   - Информация о детях (Text)
   - **Даты рождения детей (JSON):**
     ```json
     [
       {"name": "Фекла", "birthDate": "2015-05-12", "gender": "Ж"},
       {"name": "Степан", "birthDate": "2018-08-20", "gender": "М"}
     ]
     ```
5. **Хобби** (`hobbies`) - Интересы и увлечения
6. **О себе** (`aboutMe`) - Характер, привычки, что вдохновляет
7. **Дополнительная информация** (`additionalInfo`) - Любая другая информация

**Минимум для заполнения:** 3 из 7 полей

## 🔍 Проверка извлечения данных

### ✅ Экстракт работает корректно для всех полей:

**Структурированный экстракт:**
- Бот перечисляет данные в формате: `1. **ФИО**: Иванов Иван Иванович`
- Функция `extractStructuredDataFromBot()` находит и парсит эти данные
- Приоритет структурированным данным (точнее чем fallback)

**Fallback экстракт:**
- Если структурированные данные не найдены
- Ищет по паттернам в естественном языке
- Защита от географических названий и служебных слов

**Валидация:**
- Проверка корректности всех извлеченных данных
- Валидация адреса через DaData API
- Проверка возраста (14-100 лет)
- Проверка телефона (10-12 цифр)

**Специальные форматы:**
- Даты рождения детей парсятся в JSON с именами, датами и полом
- Пол определяется автоматически по имени ребенка
- Формат: `[{"name": "Имя", "birthDate": "YYYY-MM-DD", "gender": "М"|"Ж"}]`

## 🔧 Функция проверки полноты профиля

### `isProfileComplete(user)` - Для заявления

Проверяет обязательные поля:
```typescript
return (
  !!user?.firstName &&
  !!user?.lastName &&
  !!user?.dateOfBirth &&
  !!user?.phone &&
  !!user?.address &&
  !!user?.jobTitle &&
  !!user?.profession &&
  !!user?.education
);
```

**Результат:** Если `true` → можно генерировать заявление

---

### `hasAdditionalInfoComplete(user)` - Для дополнительной информации

Проверяет дополнительные поля:
```typescript
const filledFields = [
  user.employmentStatus,
  user.hobbies,
  user.aboutMe,
  user.hasChildren !== null,
  user.maritalStatus,
].filter(Boolean).length;

return filledFields >= 3;
```

**Результат:** Если `true` → дополнительная информация собрана (минимум 3 из 5 полей)
