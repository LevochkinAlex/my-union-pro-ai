## 8. Найденные проблемы и исправления

1. ✅ **Синтаксическая ошибка** - отсутствовала закрывающая скобка в блоке `if (!chat)`
2. ✅ **Реакции не отображались** - виртуальные сообщения не загружали реакции
3. ✅ **Дублирование реакций** - реакции отображались дважды в постах канала
4. ✅ **Позиция скролла не сохранялась** - использовалась абсолютная позиция вместо относительной

### Средние:
1. ✅ **Тип начального сообщения** - изменен на `'text'` для корректного отображения
2. ✅ **Поиск обращения** - исправлен поиск по `publicId` в rate endpoint
3. ✅ **Нормализация аватаров** - устранено дублирование кода

### Мелкие:
1. ✅ **Логирование** - добавлено для отладки создания сообщений
