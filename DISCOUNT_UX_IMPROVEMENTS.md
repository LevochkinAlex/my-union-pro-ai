# Улучшения UX для страницы скидок

## Исправленные проблемы (21.11.2024)

### 1. Проблема с выделением пунктов меню ✅

**Проблема:** При открытии страницы "Мои скидки" (`/dashboard/discounts/my`) выделялись ОБА пункта меню:
- Главный пункт "Скидки" (светло-синим)
- Подпункт "Мои скидки и льготы" (светло-синим)

**Причина:** Логика в `Sidebar.tsx` выделяла главный пункт, если любой из его sub-items был активен.

**Решение:**
```typescript
// components/dashboard/Sidebar.tsx

// Было:
const isMainItemActive = pathname === item.href;

// Стало:
const isMainItemActive = !isSubItemActive && pathname === item.href;
```

**Результат:**
- ✅ На `/dashboard/discounts` → выделен только "Все скидки"
- ✅ На `/dashboard/discounts/my` → выделен только "Мои скидки и льготы"

### 2. Длинный список городов на карте ✅

**Проблема:** На странице детального просмотра скидки всегда отображался весь список городов (иногда 100+ городов), что занимало много места.

**Решение:** Реализован аккордеон для раздела "На карте":

**Функционал:**
- 🔽 Если город НЕ выбран → список ЗАКРЫТ по умолчанию
- 🔼 Если конкретный город выбран → список ОТКРЫТ по умолчанию
- 📊 В заголовке показывается количество городов: "На карте (147 городов)"
- 🖱️ Клик по заголовку → открыть/закрыть список
- 🔄 Анимированная стрелка при открытии/закрытии

**Код:**
```typescript
// app/dashboard/discounts/[id]/page.tsx

const [isMapExpanded, setIsMapExpanded] = useState(!!selectedCityId);

// Заголовок-аккордеон с иконкой
<button
  onClick={() => setIsMapExpanded(!isMapExpanded)}
  className="mb-4 flex w-full items-center justify-between text-left"
>
  <h2>
    На карте
    {!selectedCityId && citiesToShow.length > 0 && (
      <span>({citiesToShow.length} городов)</span>
    )}
  </h2>
  <svg className={`${isMapExpanded ? 'rotate-180' : ''}`}>
    {/* Стрелка вниз */}
  </svg>
</button>

{/* Контент показывается только если isMapExpanded */}
{isMapExpanded && (
  // ... список городов
)}
```

**Результат:**
- ✅ Улучшена читаемость страницы
- ✅ Длинные списки не занимают весь экран
- ✅ Пользователь может раскрыть список при необходимости

## Объяснение: Почему кнопка "Скачать" заблокирована?

### Правильное поведение ✅

Кнопка "Скачать" становится активной **ТОЛЬКО** когда у скидки есть промокод.

**Логика:**
```typescript
// app/dashboard/discounts/my/page.tsx

<button
  onClick={() => handleDownloadPromoCard(discount)}
  disabled={!discount.promoCode || downloading === discount.id}
>
  Скачать
</button>
```

**Почему?**
- Карточка для скачивания содержит **QR-код** и **промокод**
- Без промокода невозможно создать карточку
- Промокод появляется только после **активации** скидки в BestBenefits

### Как активировать скидку

1. Откройте страницу скидки (например, `/dashboard/discounts/1438`)
2. Нажмите кнопку **"Использовать"**
3. Система активирует скидку в BestBenefits
4. Вы получите промокод (например, `SAMOKAT2024`)
5. Кнопка **"Скачать"** станет активной
6. Скачайте красивую PNG карточку с QR-кодом!

### Проверка активированных скидок

Используйте скрипт для проверки:
```bash
pnpm dotenv -e .env.local -- tsx scripts/check-all-preferences.ts <email>
```

**Пример вывода:**
```
📋 CLAIMED DISCOUNTS (2):
  - ID: 3764, PromoCode: BESTBENEFITS
  - ID: 1436, PromoCode: BB-9DQ7L5E
```
