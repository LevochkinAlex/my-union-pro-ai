# Changelog: Справочники и валидации

## Дата: 25 ноября 2024

### ✨ Новые функции

1. **Справочники должностей и профессий**
   - Добавлено 142 должности (разные сферы)
   - Добавлено 95 профессий (разные сферы)
   - Охват: медицина, образование, IT, производство, торговля, строительство, транспорт и др.

2. **Автокомплит в профиле**
   - Компонент `Autocomplete` с правильным позиционированием
   - Выпадающий список выровнен по левому краю поля (не по центру!)
   - Поиск от 2 символов
   - Навигация клавиатурой (↑↓, Enter, Esc)
   - Автозакрытие при клике вне

3. **Валидация ФИО через DaData**
   - Проверка корректности написания
   - Нормализация регистра
   - Поддержка тюркских суффиксов
   - Fallback на простой парсинг

4. **Валидация должностей и профессий**
   - Поиск в справочниках (точное + частичное совпадение)
   - Исправление опечаток
   - Стандартизация названий

### 🔧 Технические изменения

#### База данных
- Новые модели: `JobTitle`, `Profession`
- Индексы по полю `name` для быстрого поиска
- Seed-скрипт `prisma/seed-dictionaries.ts`

#### API
- **POST /api/dictionaries** - получение справочников
  - Возвращает: `{ jobTitles: string[], professions: string[] }`

#### Библиотеки
- `lib/dictionaries.ts` - функции поиска в справочниках:
  - `findJobTitle(query)` - поиск должности
  - `findProfession(query)` - поиск профессии
  - `getJobTitles()` - все должности
  - `getProfessions()` - все профессии

- `lib/dadata.ts` - новая функция:
  - `validateNameWithDaData(fullName)` - валидация ФИО

- `lib/chat-context-helpers.ts`:
  - Обновлен `requiresValidation()` - добавлен FIO, JOB_TITLE, PROFESSION
  - Обновлен `enhanceUserMessageWithContext()` - поддержка новых валидаций

#### Компоненты
- `components/form/Autocomplete.tsx` - универсальный автокомплит:
  - Фильтрация по вводу
  - Подсветка активного элемента
  - Клавиатурная навигация
  - Правильное позиционирование списка

#### Чат-бот
- `app/api/chat/route.ts`:
  - Валидация FIO (строка ~960)
  - Валидация JOB_TITLE (строка ~985)
  - Валидация PROFESSION (строка ~1000)

### 🧪 Тестирование

Запустить тест:
```bash
npx tsx scripts/test-full-chat-flow.ts
```

Вручную проверить:
1. Откройте тестовую сессию по ссылке из вывода скрипта
2. Пройдите весь флоу создания заявления
3. Проверьте все валидации:
   - ✅ ФИО корректируется
   - ✅ Адрес стандартизируется
   - ✅ Организация находится
   - ✅ Должность/профессия подставляются из справочника
   - ✅ Бот не зацикливается
