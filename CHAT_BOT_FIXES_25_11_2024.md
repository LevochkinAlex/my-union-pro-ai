### 1️⃣ **Поиск в справочниках: нормализация пробелов**

**Проблема:** `"врач хирург"` (с пробелом) не находился в справочнике как `"врач-хирург"` (с дефисом)

**Решение:** Добавлена автоматическая замена пробелов на дефисы в `lib/dictionaries.ts`

```typescript
// Пробуем заменить пробелы на дефисы (например, "врач хирург" → "врач-хирург")
if (normalizedQuery.includes(' ')) {
  const withHyphen = normalizedQuery.replace(/\s+/g, '-');
  const exactWithHyphen = await prisma.jobTitle.findFirst({
    where: { name: { equals: withHyphen, mode: "insensitive" } },
  });
  if (exactWithHyphen) {
    return exactWithHyphen.name;
  }
}
```

**Результат:** ✅ Теперь `"врач хирург"` → находит `"врач-хирург"`

### 2️⃣ **Извлечение адреса: приоритет валидированному от DaData**

**Проблема:** Адрес извлекался как `"Чулман 11, Челны"` вместо полного `"Респ Татарстан, г Набережные Челны, пр-кт Чулман, д. 11"`

**Решение:** В `lib/profile-extraction.ts` добавлен приоритетный поиск валидированного адреса от DaData

```typescript
// АДРЕС ВАЛИДИРОВАННЫЙ от DaData (ПРИОРИТЕТ!)
if ((botQuestion.includes('система проверила') || botQuestion.includes('система нашла адрес')) && 
    botQuestion.includes('адрес')) {
  const dadataAddrMatch = currentMsg.content.match(/адрес[^:]*:\s*\*\*([^*]+)\*\*/i);
  if (dadataAddrMatch && dadataAddrMatch[1]) {
    const validatedAddr = dadataAddrMatch[1].trim();
    if (validatedAddr.length >= 20) {
      profileData.address = validatedAddr;
    }
  }
}
```

**Результат:** ✅ Теперь извлекается полный адрес, проверенный через DaData
