## 🔍 Проверка экстракта данных (`profile-extraction.ts`)

### ✅ Что экстрактит корректно:

**Основные поля:**
- ФИО (firstName, lastName, middleName) - с защитой от географических названий
- Дата рождения (dateOfBirth) - поддержка форматов: DD.MM.YYYY, DD/MM/YYYY, "12 февраля 1970"
- Телефон (phone) - российские номера +7 или 8
- Адрес (address) - с валидацией через DaData API
- Регион (region) - автоматическое определение
- Должность (jobTitle)
- Профессия (profession)
- Образование (education)
- Организация (organizationName) - с поиском в ЕГРЮЛ/Минюст

**Дополнительные поля:**
- Занятость (employmentStatus) - WORK/STUDY/RETIREMENT
- Семейное положение (maritalStatus) - MARRIED/SINGLE/DIVORCED/WIDOWED
- Информация о супруге (spouseInfo)
- Дети (hasChildren, childrenInfo, childrenBirthDates)
- Хобби (hobbies)
- О себе (aboutMe)
- Дополнительная информация (additionalInfo)
- Город для скидок (preferredDiscountCity) - из адреса

**Специальные возможности:**
- Структурированный экстракт из подтверждающего сообщения бота
- Fallback-поиск если структурированные данные не найдены
- Валидация всех извлеченных данных
- Защита от ложных срабатываний (географические названия, служебные слова)

### ❌ Что НЕ экстрактит (и не должно):
- `awards` - награды (по требованию не собирается)
- `training` - обучение (по требованию не собирается)
- `avatarUrl` - загружается отдельно
- `signaturePath` - загружается отдельно
- Служебные поля (управляются автоматически)
