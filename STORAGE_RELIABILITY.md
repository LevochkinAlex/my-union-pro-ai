# 🔒 Надежное хранение файлов

## Текущая реализация

Файлы хранятся на том же сервере, где работает приложение, в директории `/opt/my-union-pro/public/uploads/`.

## Как это работает

1. **Прямая запись** - когда код запущен на VDS, файлы сохраняются напрямую в файловую систему
2. **SCP fallback** - если прямой путь недоступен, используется SCP для загрузки на удаленный сервер
3. **Проверка целостности** - после записи проверяется размер файла

## Настройка

### Переменные окружения

```env
# Путь к проекту на сервере
PROJECT_PATH=/opt/my-union-pro

# Или явно указать путь для загрузок
VDS_STORAGE_REMOTE_PATH=/opt/my-union-pro/public/uploads

# Публичный URL для доступа к файлам
VDS_STORAGE_PUBLIC_URL=https://myunion.pro/uploads
```

## Структура хранения

```
/opt/my-union-pro/public/uploads/
├── avatars/          # Аватары пользователей
├── posts/            # Изображения постов
├── chat/             # Файлы из чата
├── documents/        # Документы
└── knowledge/        # Файлы базы знаний
```

## Резервное копирование

Рекомендуется настроить автоматическое резервное копирование директории `/opt/my-union-pro/public/uploads/`:

```bash
# Пример cron задачи для ежедневного бэкапа
0 2 * * * tar -czf /backup/uploads-$(date +\%Y\%m\%d).tar.gz /opt/my-union-pro/public/uploads/
```

## Мониторинг

Проверка размера хранилища:
```bash
du -sh /opt/my-union-pro/public/uploads/
```

Проверка количества файлов:
```bash
find /opt/my-union-pro/public/uploads/ -type f | wc -l
```
