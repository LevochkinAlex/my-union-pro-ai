## 🔍 Что именно проверяется

### Код уже готов ✅

```typescript
// lib/organization-search.ts
export async function findOrganization(organizationName, region) {
  // 1. Ищем в локальной БД МойСоюз
  const dbOrg = await searchOrganizationInDatabase(organizationName, region);
  if (dbOrg) return dbOrg;

  // 2. ❗ Ищем через DaData API → ЕГРЮЛ/Минюст РФ
  const minjustOrg = await searchOrganizationInMinjust(organizationName, region);
  if (minjustOrg) return minjustOrg;

  return null;
}
```

### API DaData используется

- **Endpoint:** `https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/party`
- **Источник:** ЕГРЮЛ (Единый государственный реестр юридических лиц)
- **Данные:** Официальные названия, ИНН, ОГРН, адреса
- **Фильтры:** Только активные организации
