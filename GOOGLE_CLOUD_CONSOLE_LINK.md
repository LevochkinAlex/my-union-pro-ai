# 🔗 Прямая ссылка на Google Cloud Console

## Для проекта myunion-c3187:

**Прямая ссылка на проект в Google Cloud Console:**
```
https://console.cloud.google.com/home/dashboard?project=myunion-c3187
```

Или основная страница проекта:
```
https://console.cloud.google.com/welcome?project=myunion-c3187
```

## Альтернативные способы:

### 1. Через Firebase Console
Кнопка "Go to Cloud Console" обычно находится:
- На странице **Project Settings** → вкладка **General**
- В разделе **"Your project"** → рядом с **Project ID** (`myunion-c3187`)
- Или в разделе **"Service accounts"** (вкладка в Project Settings)

Если не видите кнопку, можно использовать прямую ссылку выше.

### 2. Через URL
Просто замените в URL Firebase:
```
console.firebase.google.com/project/myunion-c3187/...
```
на:
```
console.cloud.google.com/welcome?project=myunion-c3187
```

### 3. Через выпадающее меню проекта
В Firebase Console в шапке есть название проекта "MyUnion" с выпадающим меню - там может быть опция перехода в Cloud Console.
