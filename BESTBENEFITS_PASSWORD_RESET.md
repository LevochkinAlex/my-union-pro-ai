# Восстановление пароля BestBenefits

## 🎯 Проблема

Пользователь `ceo@yappix.ru` был создан в BestBenefits со случайным паролем, который неизвестен.

## ✅ Решение: Восстановление пароля через веб-интерфейс

### Шаг 1: Перейдите на страницу входа
Откройте: https://bestbenefits.ru/login

### Шаг 2: Нажмите "Забыли пароль?"
На странице входа есть кнопка "Забыли пароль?" рядом с полем пароля.

### Шаг 3: Введите email
Введите: `ceo@yappix.ru`

### Шаг 4: Проверьте почту
На email `ceo@yappix.ru` придет письмо с инструкциями по восстановлению пароля.

### Шаг 5: Установите новый пароль
Следуйте инструкциям в письме и установите новый пароль (например: `w+Aj7UH5/FpB`).

## 🔄 Альтернативное решение: Пересоздание пользователя

Если восстановление пароля не работает, можно попробовать удалить пользователя из BestBenefits (через поддержку) и создать заново:

```bash
pnpm dotenv -e .env.local -- tsx scripts/create-bb-user-with-password.ts ceo@yappix.ru "w+Aj7UH5/FpB"
```

**Но это требует:**
- Удаления пользователя через поддержку BestBenefits
- Или использования другого email для тестирования
